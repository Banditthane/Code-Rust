# Exercise 02: Output Challenge

**Chapter:** 01 - Rust Fundamentals  
**Level:** L1 - Beginner  
**Score:** 10 Points

## 1. Objective

ฝึกใช้งาน `print!()` และ `println!()` เพื่อจัดรูปแบบการแสดงผล

## 2. Concepts

- Output
- `print!()`
- `println!()`
- New Line `\n`

## 3. Problem

เขียนโปรแกรมให้แสดงผลลัพธ์ตามตัวอย่างด้านล่าง:

## 4. Expected Output

```text
Rust
I am learning Rust.
Let's build something!
```

## 5. Requirements

- ใช้ `print!()` อย่างน้อย 1 ครั้ง
- ใช้ `println!()` อย่างน้อย 1 ครั้ง
- แสดงข้อความตามลำดับที่กำหนด
- โปรแกรมต้อง Compile และ Run ได้

## 6. Restrictions

- ห้ามใช้ Variables
- ห้ามใช้ Loops
- ห้ามใช้ Functions เพิ่มเติม
- ใช้เฉพาะ Output Macros ที่เรียน

## 7. Acceptance Criteria

| Criteria                 | Points |
| ------------------------ | -----: |
