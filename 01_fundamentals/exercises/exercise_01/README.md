# Exercise 01: Personal Profile

**Chapter:** 01 - Rust Fundamentals  
**Level:** L1 - Beginner  
**Score:** 10 Points

## 1. Objective

ฝึกเขียนโปรแกรม Rust เบื้องต้น โดยใช้ `fn main()` และ `println!()` เพื่อแสดงข้อมูลส่วนตัว

## 2. Concepts

- Rust Syntax
- Main Function
- Output
- Comments

## 3. Problem

สร้างโปรแกรมแสดงข้อมูลส่วนตัวของคุณ โดยต้องมีข้อมูลดังนี้:

1. Name
2. Age
3. Country
4. Programming Language
5. Learning Goal

## 4. Requirements

- ใช้ `fn main()`
- ใช้ `println!()` อย่างน้อย 5 ครั้ง
- มี Comment อย่างน้อย 2 จุด
- จัดรูปแบบผลลัพธ์ให้อ่านง่าย
- โปรแกรมต้อง Compile และ Run ได้

## 5. Expected Output

ตัวอย่างผลลัพธ์:

```text
========================
      PERSONAL PROFILE
========================
Name: Alex
Age: 20
Country: Thailand
Language: Rust
Goal: Become a Rust Developer
========================
```

ข้อมูลในตัวอย่างสามารถเปลี่ยนเป็นข้อมูลของผู้เรียนได้

## 6. Restrictions

- ยังไม่ต้องใช้ Variables
- ยังไม่ต้องใช้ Input
- ใช้เฉพาะคำสั่งพื้นฐานที่เรียนในบทนี้

## 7. Acceptance Criteria

| Criteria                  | Points |
| ------------------------- | -----: |
| ใช้ Main Function ถูกต้อง |      2 |
| แสดงข้อมูลครบ             |      3 |
| ใช้ Comments ถูกต้อง      |      2 |
| จัดรูปแบบผลลัพธ์          |      1 |
| โปรแกรม Run ได้           |      2 |
| Total                     |     10 |

## 8. Run Program

```powershell
cargo run
```
