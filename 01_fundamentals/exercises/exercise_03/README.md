# Exercise 03: Comment Challenge

**Chapter:** 01 - Rust Fundamentals  
**Level:** L1 - Beginner  
**Score:** 10 Points

## 1. Objective

ฝึกเขียน Comments เพื่ออธิบายการทำงานของโปรแกรม Rust

## 2. Concepts

- Single-line Comments
- Multi-line Comments
- Inline Comments
- Rust Syntax

## 3. Problem

สร้างโปรแกรมแสดงข้อมูลการเรียนรู้ Rust โดยต้องมี Comments ประกอบโค้ด

## 4. Requirements

โปรแกรมต้องมี:

1. Single-line Comment อย่างน้อย 2 จุด
2. Multi-line Comment อย่างน้อย 1 จุด
3. `println!()` อย่างน้อย 3 ครั้ง
4. ข้อความแสดงผลเกี่ยวกับการเรียน Rust
5. โปรแกรมต้อง Compile และ Run ได้

## 5. Expected Output

```text
========================
     RUST LEARNING
========================
Topic: Rust Fundamentals
Level: Beginner
Status: Learning
========================
```

## 6. Restrictions

- ห้ามใช้ Variables
- ห้ามใช้ Loops
- ห้ามใช้ Input
- ใช้เฉพาะ Syntax ที่เรียนในบทนี้

## 7. Acceptance Criteria

| Criteria               | Points |
| ---------------------- | -----: |
| Single-line Comments   |      2 |
| Multi-line Comment     |      2 |
| ใช้ println!() ถูกต้อง |      2 |
| ผลลัพธ์ตรงตามโจทย์     |      2 |
| โปรแกรม Run ได้        |      2 |
| Total                  |     10 |

## 8. Run Program

```powershell
cargo run
```

## 9. Completion

- [ ] มี Single-line Comments
- [ ] มี Multi-line Comment
- [ ] แสดงข้อความได้ถูกต้อง
- [ ] โปรแกรม Run สำเร็จ

## 10. Reflection

1. Comments ถูกนำไปประมวลผลโดย Compiler หรือไม่?
2. `//` ต่างจาก `/* */` อย่างไร?
3. การเขียน Comments ที่ดีควรเป็นอย่างไร?
