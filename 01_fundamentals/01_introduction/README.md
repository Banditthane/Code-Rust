# Lesson 01: Introduction to Rust

**Chapter:** 01 - Rust Fundamentals  
**Level:** L1 - Beginner  
**Status:** Learning

## 1. Overview

Rust เป็นภาษาโปรแกรมที่ออกแบบมาเพื่อประสิทธิภาพ ความน่าเชื่อถือ และความปลอดภัยในการจัดการ Memory

Rust เหมาะสำหรับการพัฒนาโปรแกรมที่ต้องการประสิทธิภาพสูงและการควบคุมทรัพยากรของระบบ

## 2. Learning Objectives

เมื่อเรียนจบบทนี้ ผู้เรียนจะสามารถ:

- อธิบายได้ว่า Rust คืออะไร
- เข้าใจจุดเด่นของภาษา Rust
- รู้จักลักษณะการใช้งาน Rust
- เข้าใจเหตุผลที่ควรเรียน Rust

## 3. What is Rust?

Rust เป็นภาษาโปรแกรมที่เน้น:

1. Performance
2. Reliability
3. Productivity

Rust มีระบบตรวจสอบความปลอดภัยของ Memory ในระหว่าง Compile โดยไม่จำเป็นต้องใช้ Garbage Collector

## 4. Why Learn Rust?

เหตุผลที่ควรเรียน Rust:

- ประสิทธิภาพในการทำงานสูง
- มีระบบจัดการ Memory ที่ปลอดภัย
- ตรวจสอบข้อผิดพลาดหลายประเภทตั้งแต่ Compile Time
- รองรับการเขียนโปรแกรมหลายรูปแบบ
- มีเครื่องมือ Cargo สำหรับจัดการโปรเจกต์

## 5. Where is Rust Used?

ตัวอย่างการใช้งาน:

- System Programming
- Web Development
- Command Line Applications
- Game Development
- Embedded Systems

## 6. First Rust Program

ตัวอย่างโปรแกรม Rust:

```rust
fn main() {
    println!("Hello, Rust!");
}
```

ผลลัพธ์:

```text
Hello, Rust!
```
