# Lesson 04: Final Project

## Overview

บทเรียนนี้เป็นการนำความรู้ทั้งหมดจาก Rust Learning Roadmap มาสร้างโปรแกรมขนาดเล็กแบบครบวงจร

ผู้เรียนจะต้องวิเคราะห์โจทย์ ออกแบบโครงสร้าง พัฒนาโปรแกรม จัดการข้อมูล ทดสอบ และปรับปรุงโค้ดด้วยตนเอง

## Learning Objectives

- วางแผนและออกแบบโปรแกรมได้
- สร้างโปรแกรมที่มีหลาย Module ได้
- ใช้ Struct และ Enum จัดการข้อมูลได้
- ใช้ Function แยกหน้าที่การทำงานได้
- ใช้ Collections จัดเก็บข้อมูลได้
- รับข้อมูลจากผู้ใช้ผ่าน CLI ได้
- อ่านและเขียนไฟล์ได้
- จัดการข้อผิดพลาดด้วย Result และ Option ได้
- เขียน Tests สำหรับตรวจสอบโปรแกรมได้

## Final Project Requirements

โปรแกรมที่พัฒนาต้องมีความสามารถพื้นฐานดังนี้:

### 1. User Interface

- มีเมนูหลัก
- รับคำสั่งจากผู้ใช้
- แสดงผลลัพธ์ที่เข้าใจง่าย
- มีคำสั่งออกจากโปรแกรม

### 2. Data Management

- ใช้ Struct หรือ Enum ตามความเหมาะสม
- สามารถเพิ่มข้อมูลได้
- สามารถแสดงข้อมูลได้
- สามารถแก้ไขหรือลบข้อมูลได้ตามขอบเขตของโปรแกรม

### 3. Data Persistence

- สามารถบันทึกข้อมูลลงไฟล์ได้
- สามารถอ่านข้อมูลกลับมาได้
- ข้อมูลไม่ควรสูญหายเมื่อปิดโปรแกรมตามรูปแบบการจัดเก็บที่กำหนด

### 4. Error Handling

- ตรวจสอบข้อมูลจากผู้ใช้
- จัดการกรณีข้อมูลไม่ถูกต้อง
- จัดการกรณีอ่านหรือเขียนไฟล์ไม่สำเร็จ
- ไม่ปล่อยให้โปรแกรม Panic จากข้อมูลที่ผู้ใช้ป้อนได้โดยไม่มีเหตุผล

### 5. Testing

- มี Unit Tests สำหรับ Function สำคัญ
- มี Tests สำหรับกรณีปกติ
- มี Tests สำหรับกรณีผิดพลาด
- ทดสอบการทำงานของส่วนต่าง ๆ ที่สำคัญ

## Suggested Project Structure

```text
src/
├── main.rs
├── models/
│   └── mod.rs
├── services/
│   └── mod.rs
├── storage/
│   └── mod.rs
└── utils/
    └── mod.rs

tests/
└── integration_test.rs
```

โครงสร้างนี้เป็นแนวทางตัวอย่าง สามารถปรับเปลี่ยนได้ตามความเหมาะสมของโปรเจกต์

## Development Workflow

1. วิเคราะห์โจทย์และกำหนดขอบเขต
2. ออกแบบข้อมูลและโครงสร้างโปรแกรม
3. สร้าง Cargo Project
4. พัฒนา Model และ Function หลัก
5. แบ่งโค้ดออกเป็น Module
6. พัฒนา CLI สำหรับรับคำสั่ง
7. เพิ่มระบบอ่านและเขียนไฟล์
8. เพิ่ม Error Handling
9. เขียน Unit Tests และ Integration Tests
10. ตรวจสอบและปรับปรุงโค้ด

## Quality Requirements

ก่อนส่งมอบโปรเจกต์ ควรตรวจสอบคำสั่งต่อไปนี้จาก Project Root:

```powershell
cargo check
cargo fmt --check
cargo clippy
cargo test
cargo run
```

ผู้เรียนควรสามารถเริ่มต้นโปรเจกต์ Rust ขนาดเล็กได้ด้วยตนเอง ตั้งแต่การวางแผนจนถึงการทดสอบและส่งมอบโปรแกรม
