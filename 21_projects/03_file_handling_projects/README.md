# Lesson 03: File Handling Projects

## Overview

โปรแกรมหลายประเภทจำเป็นต้องจัดเก็บข้อมูลเพื่อให้สามารถนำกลับมาใช้งานได้ในภายหลัง

บทเรียนนี้จะฝึกอ่านและเขียนไฟล์ด้วย Rust รวมถึงการจัดการข้อผิดพลาดที่อาจเกิดขึ้นระหว่างการทำงานกับไฟล์

## Learning Objectives

- เข้าใจการทำงานกับไฟล์ใน Rust
- อ่านข้อมูลจากไฟล์
- เขียนข้อมูลลงไฟล์
- เพิ่มข้อมูลต่อท้ายไฟล์
- ตรวจสอบว่าไฟล์มีอยู่หรือไม่
- จัดการข้อผิดพลาดจาก File I/O
- แยกการทำงานเกี่ยวกับไฟล์ออกเป็น Function

## 1. File System Module

Rust มี Module สำหรับทำงานกับไฟล์ เช่น

- `std::fs` สำหรับการอ่านและเขียนไฟล์
- `std::io` สำหรับ Input/Output และ Error
- `std::path` สำหรับจัดการ Path ของไฟล์

## 2. Read a File

สามารถใช้ `std::fs::read_to_string()` เพื่ออ่านเนื้อหาทั้งไฟล์เป็น String

แนวคิดการทำงาน:

1. ระบุ Path ของไฟล์
2. อ่านไฟล์
3. ตรวจสอบผลลัพธ์
4. นำข้อความไปประมวลผล

## 3. Write a File

สามารถใช้ `std::fs::write()` เพื่อเขียนข้อความลงไฟล์

ควรเข้าใจว่า `write()` จะเขียนทับเนื้อหาเดิมของไฟล์เมื่อไฟล์นั้นมีอยู่แล้ว

## 4. Append to a File

หากต้องการเพิ่มข้อมูลต่อท้ายไฟล์โดยไม่ลบข้อมูลเดิม สามารถใช้ `std::fs::OpenOptions`

แนวคิดสำคัญ:

- เปิดไฟล์ด้วยโหมด Append
- เขียนข้อมูลต่อท้าย
- ตรวจสอบผลลัพธ์จากการเขียน

## 5. Handle File Errors

การทำงานกับไฟล์อาจเกิดข้อผิดพลาด เช่น

- ไม่พบไฟล์
- ไม่มีสิทธิ์เข้าถึงไฟล์
- Path ไม่ถูกต้อง
- เกิดปัญหาระหว่างอ่านหรือเขียน

ควรใช้ `Result<T, E>` และ `?` เพื่อส่งต่อข้อผิดพลาดไปยังส่วนที่รับผิดชอบจัดการ

## 6. Data Persistence

Data Persistence คือการจัดเก็บข้อมูลให้คงอยู่หลังจากโปรแกรมปิดตัวลง

ตัวอย่าง:

- โปรแกรม Todo บันทึกรายการลงไฟล์
- โปรแกรม Expense Tracker บันทึกรายรับรายจ่าย
- โปรแกรม Student Management บันทึกข้อมูลนักเรียน

สำหรับโปรเจกต์ในบทนี้สามารถใช้ไฟล์ข้อความธรรมดาเป็นรูปแบบจัดเก็บข้อมูลเบื้องต้นได้

## Best Practices

- ตรวจสอบ Path ของไฟล์ก่อนใช้งาน
- จัดการ Error ทุกครั้งที่อ่านหรือเขียนไฟล์
- แยก Function สำหรับอ่านและเขียนข้อมูล
- ระวังการเขียนทับข้อมูลเดิม
- กำหนดรูปแบบข้อมูลให้ชัดเจน
- ทดสอบทั้งกรณีไฟล์มีอยู่และไม่มีอยู่
- อย่าเก็บข้อมูลสำคัญโดยไม่พิจารณาเรื่องความปลอดภัย
