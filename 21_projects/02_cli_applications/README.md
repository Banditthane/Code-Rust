# Lesson 02: CLI Applications

## Overview

CLI (Command Line Interface) คือรูปแบบโปรแกรมที่ผู้ใช้โต้ตอบผ่าน Terminal หรือ Command Prompt

บทเรียนนี้จะฝึกสร้างโปรแกรมที่รับคำสั่งและข้อมูลจากผู้ใช้ ประมวลผล และแสดงผลผ่าน Terminal

## Learning Objectives

- เข้าใจการทำงานของ CLI Application
- รับข้อมูลจากผู้ใช้ด้วย Standard Input
- แสดงผลผ่าน Standard Output
- แปลงข้อความเป็นชนิดข้อมูลที่ต้องการ
- ตรวจสอบข้อมูลก่อนประมวลผล
- สร้างเมนูและรับคำสั่งจากผู้ใช้
- จัดการ Input ที่ไม่ถูกต้องได้

## 1. Standard Output

ใช้ `println!()` เพื่อแสดงข้อความหรือผลลัพธ์

```rust
fn main() {
    println!("Welcome to Rust CLI");
}
```

## 2. Standard Input

ใช้ `std::io` เพื่อรับข้อมูลจากผู้ใช้

```rust
use std::io;

fn main() {
    let mut input = String::new();

    println!("Enter your name:");

    io::stdin()
        .read_line(&mut input)
        .expect("Failed to read input");

    println!("Hello, {}", input.trim());
}
```

## 3. Convert User Input

ข้อมูลที่อ่านด้วย `read_line()` จะเป็นข้อความชนิด String

หากต้องการตัวเลข สามารถใช้ `parse()` เพื่อแปลงชนิดข้อมูลได้

```rust
let number: i32 = input.trim().parse()
    .expect("Please enter a valid number");
```

สำหรับโปรแกรมจริง ควรจัดการกรณีที่แปลงข้อมูลไม่สำเร็จด้วย `Result` แทนการใช้ `expect()` โดยไม่ตรวจสอบ

## 4. Create a Menu

โปรแกรม CLI สามารถใช้ Loop เพื่อแสดงเมนูซ้ำได้

ตัวอย่างรูปแบบเมนู:

```text
===== MENU =====
1. Add
2. View
3. Update
4. Delete
0. Exit
Select:
```

แนวคิดการทำงาน:

1. แสดงเมนู
2. รับคำสั่งจากผู้ใช้
3. ตรวจสอบคำสั่ง
4. เรียก Function ที่เกี่ยวข้อง
5. กลับไปแสดงเมนู
6. ออกจากโปรแกรมเมื่อเลือก Exit

## 5. Validate User Input

ควรตรวจสอบข้อมูลก่อนนำไปใช้งาน เช่น

- ผู้ใช้ป้อนตัวเลขได้ถูกต้องหรือไม่
- คำสั่งอยู่ในรายการที่รองรับหรือไม่
- ข้อมูลที่จำเป็นถูกป้อนครบหรือไม่
- จำนวนเงินหรือคะแนนอยู่ในช่วงที่อนุญาตหรือไม่

## 6. Error Handling

ควรใช้ `Result<T, E>` หรือ `Option<T>` ตามลักษณะของข้อมูลและข้อผิดพลาด

ตัวอย่างข้อผิดพลาดที่ควรรองรับ:

- ป้อนข้อความแทนตัวเลข
- เลือกเมนูที่ไม่มีอยู่
- ป้อนข้อมูลว่าง
- ป้อนค่าที่อยู่นอกช่วงที่กำหนด

## Best Practices

- แยก Function รับข้อมูลออกจาก Function ประมวลผล
- ใช้ `trim()` เมื่อต้องการตัดช่องว่างและ Newline รอบข้อความ
- ตรวจสอบข้อมูลก่อนใช้งาน
- แสดงข้อความแจ้งข้อผิดพลาดที่เข้าใจง่าย
- เปิดโอกาสให้ผู้ใช้ลองป้อนข้อมูลใหม่
- ไม่ควรใช้ `unwrap()` กับข้อมูลจากผู้ใช้โดยไม่มีการตรวจสอบ
