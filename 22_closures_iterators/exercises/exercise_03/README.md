# Exercise 03: Iterator Basics

## Project: iterator_basics

ระดับความยาก: Medium

## 1. วัตถุประสงค์

ฝึกสร้าง Iterator จาก Vector และเข้าใจความแตกต่างระหว่าง `iter()`, `iter_mut()` และ `into_iter()`

## 2. โจทย์

สร้างโปรแกรมจัดการรายการตัวเลข โดยใช้ Vector เป็นชุดข้อมูลหลัก

กำหนดข้อมูลเริ่มต้น:

```text
[10, 20, 30, 40, 50]
```

แบ่งการทำงานออกเป็น 3 ส่วน

### ส่วนที่ 1: อ่านข้อมูลด้วย iter()

- สร้าง Iterator จาก Vector
- อ่านข้อมูลทีละรายการ
- ทดลองเรียก `next()` เพื่อดึงข้อมูล
- แสดงผลข้อมูลที่ได้รับ
- ตรวจสอบผลเมื่อไม่มีข้อมูลเหลือ

### ส่วนที่ 2: แก้ไขข้อมูลด้วย iter_mut()

- สร้าง Vector ที่สามารถแก้ไขได้
- ใช้ `iter_mut()` เพื่อเข้าถึงสมาชิก
- เพิ่มค่าของสมาชิกทุกตัวขึ้น 10
- แสดง Vector หลังแก้ไข

### ส่วนที่ 3: ย้าย Ownership ด้วย into_iter()

- สร้าง Vector ชุดใหม่
- ใช้ `into_iter()` เพื่อดึงสมาชิกออกมา
- แสดงสมาชิกทีละรายการ
- สังเกตว่า Vector ต้นทางยังสามารถใช้งานได้หรือไม่หลังย้าย Ownership

## 3. ข้อกำหนด

- ต้องใช้ `iter()`
- ต้องใช้ `iter_mut()`
- ต้องใช้ `into_iter()`
- ต้องทดลองใช้ `next()` อย่างน้อยหนึ่งครั้ง
- ต้องแสดงผลข้อมูลก่อนและหลังแก้ไข
- ต้องอธิบายความแตกต่างด้าน Ownership ของทั้งสาม Method

## 4. ข้อมูลทดสอบ

| รายการ          | ค่า                    |
| --------------- | ---------------------- |
| Vector เริ่มต้น | `[10, 20, 30, 40, 50]` |
| ค่าที่เพิ่ม     | `10`                   |
| จำนวนสมาชิก     | `5`                    |

## 5. ผลลัพธ์ที่คาดหวัง

```text
Original Vector: [10, 20, 30, 40, 50]

Iterator Next:
Some(10)
Some(20)

Modified Vector: [20, 30, 40, 50, 60]

Into Iterator:
20
30
40
50
60
```

หมายเหตุ: ส่วน `into_iter()` ให้ใช้ Vector ชุดที่เหมาะสมกับการทดลอง Ownership โดยไม่จำเป็นต้องเป็น Vector ตัวเดียวกับส่วนก่อนหน้า

## 6. เงื่อนไขและข้อจำกัด

- ต้องใช้ Iterator จริง ไม่ใช้ Index เพื่อวนอ่านข้อมูลทุกตัว
- ห้ามใช้ Loop แบบ Index แทน `iter()` และ `iter_mut()` ในส่วนที่โจทย์กำหนด
- ต้องแยกการทดลอง Ownership ให้ชัดเจน
- ห้ามใช้ `clone()` เพื่อหลีกเลี่ยงการย้าย Ownership ในส่วน `into_iter()`
- ต้องไม่ใช้ข้อมูลที่คำนวณไว้ล่วงหน้าแทนการประมวลผล
