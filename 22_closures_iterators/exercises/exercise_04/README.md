# Exercise 04: Iterator Challenge

## Project: iterator_challenge

ระดับความยาก: Challenge

## 1. วัตถุประสงค์

ประยุกต์ใช้ Closure และ Iterator เพื่อสร้างโปรแกรมวิเคราะห์คะแนนนักเรียน โดยใช้ Iterator Adapters และ Consumers หลายรูปแบบร่วมกัน

## 2. โจทย์

สร้างโปรแกรมวิเคราะห์คะแนนนักเรียนจาก Vector โดยต้องสามารถคำนวณและแสดงข้อมูลต่อไปนี้

1. คะแนนทั้งหมด
2. คะแนนที่ผ่านเกณฑ์
3. คะแนนที่ไม่ผ่านเกณฑ์
4. คะแนนหลังแปลงเป็นคะแนนโบนัส
5. ผลรวมคะแนนทั้งหมด
6. คะแนนเฉลี่ย
7. จำนวนผู้ที่ผ่านเกณฑ์
8. คะแนนสูงสุด

## 3. ข้อมูลเริ่มต้น

กำหนดคะแนนนักเรียนดังนี้:

```text
[45, 60, 75, 80, 90, 55, 100, 35]
```

กำหนดเกณฑ์:

| รายการ               |     ค่า |
| -------------------- | ------: |
| คะแนนผ่าน            |      50 |
| คะแนนโบนัส           | เพิ่ม 5 |
| คะแนนสูงสุดที่อนุญาต |     100 |

## 4. ข้อกำหนดด้าน Iterator

ต้องใช้ Method ต่อไปนี้ให้ครบตามหน้าที่:

### 4.1 iter()

ใช้เข้าถึงคะแนนโดยไม่ย้าย Ownership ของ Vector ต้นทาง

### 4.2 filter()

ใช้แยกคะแนนที่ผ่านเกณฑ์และไม่ผ่านเกณฑ์

### 4.3 map()

ใช้แปลงคะแนนเพื่อคำนวณคะแนนโบนัส

### 4.4 fold()

ใช้สะสมผลรวมคะแนน

### 4.5 collect()

ใช้รวบรวมคะแนนที่ผ่านการแปลงหรือกรองแล้วเป็น Vector ใหม่

### 4.6 count()

ใช้หาจำนวนสมาชิกที่ผ่านเงื่อนไข

### 4.7 sum()

ใช้หาผลรวมคะแนน

นอกจากนี้ สามารถเลือกใช้ Method อื่น เช่น `max()`, `min()` หรือ `filter_map()` เพื่อเพิ่มความสามารถของโปรแกรมได้

## 5. ข้อกำหนดด้าน Closure

- ต้องใช้ Closure กับ `filter()`
- ต้องใช้ Closure กับ `map()`
- ต้องใช้ Closure กับ `fold()`
- ต้องไม่เขียนการคำนวณผลลัพธ์ทั้งหมดด้วย Loop แบบเดิมแทน Iterator
- ตั้งชื่อ Closure และตัวแปรให้สื่อความหมาย

## 6. ผลลัพธ์ที่คาดหวัง

จากข้อมูลทดสอบ โปรแกรมควรได้ผลลัพธ์ในลักษณะดังนี้:

```text
Original Scores: [45, 60, 75, 80, 90, 55, 100, 35]

Passed Scores: [60, 75, 80, 90, 55, 100]
Failed Scores: [45, 35]

Bonus Scores: [50, 65, 80, 85, 95, 60, 105, 40]

Total Score: 540
Average Score: 67.50
Passed Students: 6
Highest Score: 100
```

หมายเหตุ:

- ค่าเฉลี่ยคำนวณจากคะแนนเดิม
- คะแนนโบนัสคำนวณจากคะแนนเดิมบวก 5
- คะแนนโบนัสไม่จำเป็นต้องจำกัดไม่เกิน 100 เว้นแต่ผู้เรียนเลือกเพิ่มเงื่อนไขนี้เอง
- คะแนนสูงสุดคำนวณจากคะแนนเดิม

## 7. เงื่อนไขและข้อจำกัด

- ต้องใช้ Vector เป็นข้อมูลหลัก
- ต้องใช้ Iterator Adapters และ Consumers ตามที่กำหนด
- ห้ามเขียนค่าผลลัพธ์ไว้ล่วงหน้า
- ห้ามใช้ `unwrap()` โดยไม่ตรวจสอบความเป็นไปได้ของข้อมูลว่าง
- ต้องจัดการกรณี Vector ไม่มีคะแนน เพื่อไม่ให้เกิดการหารด้วยศูนย์
- ต้องไม่แก้ไข Vector ต้นฉบับโดยไม่จำเป็น
- ต้องแสดงค่าเฉลี่ยด้วยทศนิยม 2 ตำแหน่ง
- ต้องใช้ชนิดข้อมูลที่เหมาะสมกับการคำนวณ

## 8. ส่วนขยายเพิ่มเติม (Optional)

หากทำโจทย์หลักสำเร็จแล้ว ให้เพิ่มความสามารถต่อไปนี้:

- แสดงคะแนนต่ำสุด
- เรียงลำดับคะแนนจากน้อยไปมาก
- ค้นหาคะแนนที่เท่ากับค่าที่กำหนด
- แสดงเฉพาะคะแนนที่หารด้วย 5 ลงตัว
- สร้างข้อความสรุปผลโดยใช้ Closure
- ทดลองใช้ `filter_map()` กับข้อมูลที่ต้องแปลงเป็นตัวเลข
