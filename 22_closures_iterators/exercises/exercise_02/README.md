# Exercise 02: Closure Traits

## Project: closure_traits

ระดับความยาก: Easy-Medium

## 1. วัตถุประสงค์

ฝึกใช้งาน Closure ที่มีพฤติกรรมแตกต่างกันตาม Trait ได้แก่ `Fn`, `FnMut` และ `FnOnce` รวมถึงการใช้ `move`

## 2. โจทย์

สร้างโปรแกรมจำลองระบบจัดการคะแนนและข้อความ โดยแบ่งการทำงานเป็น 3 ส่วน

### ส่วนที่ 1: Immutable Capture

สร้าง Closure ที่อ่านค่าจากตัวแปรภายนอกโดยไม่แก้ไขค่า

สิ่งที่ต้องทำ:

- กำหนดข้อความหรือชื่อผู้ใช้ไว้ภายนอก Closure
- สร้าง Closure เพื่ออ่านข้อความดังกล่าว
- เรียกใช้งาน Closure มากกว่าหนึ่งครั้ง

### ส่วนที่ 2: Mutable Capture

สร้าง Closure ที่แก้ไขค่าตัวแปรภายนอก

สิ่งที่ต้องทำ:

- กำหนดตัวแปรสำหรับนับจำนวนครั้ง
- สร้าง Closure เพื่อเพิ่มค่าตัวนับ
- เรียกใช้งานหลายครั้ง
- แสดงค่าตัวนับหลังการเรียกใช้งาน

### ส่วนที่ 3: Move Closure

สร้าง Closure ที่จับข้อมูลด้วย `move`

สิ่งที่ต้องทำ:

- สร้าง `String` ไว้ภายนอก Closure
- ใช้ `move` เพื่อจับข้อมูลเข้าไปใน Closure
- แสดงข้อมูลจากภายใน Closure
- สังเกตผลของ Ownership ที่เกิดขึ้นกับตัวแปรเดิม

## 3. ข้อกำหนด

- ต้องมี Closure ที่ใช้พฤติกรรมแบบ `Fn`
- ต้องมี Closure ที่ใช้พฤติกรรมแบบ `FnMut`
- ต้องมี Closure ที่ใช้พฤติกรรมแบบ `FnOnce`
- ต้องมีการใช้ `move`
- ต้องอธิบายว่าทำไม Closure แต่ละตัวจึงอยู่ใน Trait นั้น
- ต้องไม่ละเมิดกฎ Borrowing ของ Rust

หมายเหตุ: การใช้ `move` เพียงอย่างเดียวไม่ได้รับประกันว่า Closure จะเป็น `FnOnce` เท่านั้น ต้องพิจารณาวิธีใช้งานค่าที่จับมาด้วย

## 4. ข้อมูลทดสอบ

| รายการ                     | ค่าเริ่มต้น     |
| -------------------------- | --------------- |
| Username                   | Alice           |
| Counter                    | 0               |
| จำนวนครั้งที่เพิ่ม Counter | 3               |
| Message                    | Hello from Rust |

## 5. ผลลัพธ์ที่คาดหวัง

โปรแกรมควรแสดงผลลัพธ์ในลักษณะดังนี้:

```text
User: Alice
User: Alice

Counter: 3

Message: Hello from Rust
```

นอกจากผลลัพธ์แล้ว ต้องสามารถอธิบายได้ว่าแต่ละ Closure ใช้การจับค่ารูปแบบใด

## 6. เงื่อนไขและข้อจำกัด

- ต้องเขียน Closure ด้วยตนเอง
- ห้ามใช้ Global Variable
- ต้องไม่แก้ไขข้อมูลในส่วน Immutable Capture
- ส่วน Mutable Capture ต้องแก้ไขค่าผ่าน Closure
- ส่วน Move Closure ต้องใช้ `move` จริง
- ห้ามใช้ `clone()` เพื่อหลีกเลี่ยงการทำความเข้าใจ Ownership ในโจทย์ส่วน Move Closure
- ต้องอธิบายผลของการย้าย Ownership ด้วยตนเอง

## 7. สิ่งที่ต้องส่ง

- ไฟล์ `src/main.rs`
- ผลลัพธ์จากการรัน
- คำอธิบายสั้น ๆ ของ Fn, FnMut และ FnOnce ในโปรแกรมของตนเอง
