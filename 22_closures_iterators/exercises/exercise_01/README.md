# Exercise 01: Closure Basics

## Project: closure_basics

ระดับความยาก: Easy

## 1. วัตถุประสงค์

ฝึกสร้างและเรียกใช้งาน Closure โดยใช้พารามิเตอร์ การคืนค่า และการเข้าถึงตัวแปรภายนอก

## 2. โจทย์

สร้างโปรแกรมสำหรับคำนวณข้อมูลพื้นฐานด้วย Closure โดยต้องมีความสามารถดังนี้

1. สร้าง Closure สำหรับบวกตัวเลข 2 จำนวน
2. สร้าง Closure สำหรับคูณตัวเลข 2 จำนวน
3. สร้าง Closure สำหรับยกกำลังสอง
4. สร้าง Closure สำหรับตรวจสอบว่าตัวเลขเป็นเลขคู่หรือไม่
5. สร้าง Closure สำหรับแสดงข้อความต้อนรับ โดยอ่านข้อความจากตัวแปรภายนอก

## 3. ข้อกำหนด

- ต้องใช้ Closure อย่างน้อย 5 ตัว
- Closure สำหรับคำนวณต้องรับพารามิเตอร์ตามความเหมาะสม
- Closure ที่คืนค่าต้องคืนผลลัพธ์ที่ถูกต้อง
- ต้องมี Closure ที่เข้าถึงตัวแปรจาก Environment ภายนอก
- ต้องเรียกใช้งาน Closure ทุกตัว
- แสดงผลลัพธ์ด้วย `println!()`

## 4. ข้อมูลทดสอบ

ใช้ข้อมูลต่อไปนี้ในการทดสอบ:

| รายการ                     |   ค่า |
| -------------------------- | ----: |
| ตัวเลข A                   |    10 |
| ตัวเลข B                   |     5 |
| ตัวเลขสำหรับยกกำลังสอง     |     6 |
| ตัวเลขสำหรับตรวจสอบคู่/คี่ |     8 |
| ชื่อผู้ใช้                 | Alice |

## 5. ผลลัพธ์ที่คาดหวัง

โปรแกรมควรแสดงผลลัพธ์ในลักษณะดังนี้:

```text
Addition: 15
Multiplication: 50
Square: 36
Is Even: true
Welcome Alice
```

## 6. เงื่อนไขและข้อจำกัด

- ห้ามใช้ฟังก์ชัน `fn` แทน Closure ในส่วนที่โจทย์กำหนด
- ต้องสร้าง Closure และเรียกใช้งานจริง
- ไม่กำหนดให้ใช้ตัวแปรกลางทุกขั้นตอน สามารถเขียนนิพจน์ใน `println!()` ได้
- ตั้งชื่อตัวแปรให้สื่อความหมาย
- ห้ามใช้ค่าผลลัพธ์ที่คำนวณไว้ล่วงหน้าแทนการประมวลผล

## 7. สิ่งที่ต้องส่ง

- ไฟล์ `src/main.rs`
- โค้ดที่สามารถรันได้
- ผลลัพธ์จากการทดสอบโปรแกรม
