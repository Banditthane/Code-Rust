# Exercise 01: Box Practice

**ระดับ:** Easy

**โปรเจกต์:** `box_practice`

## วัตถุประสงค์

ฝึกใช้ `Box<T>` เพื่อจัดเก็บข้อมูลบน Heap และเรียนรู้การเข้าถึงข้อมูลภายใน Box

## โจทย์

สร้างโปรแกรมจัดการข้อมูลสินค้า โดยใช้ `Box<T>` จัดเก็บข้อมูลสินค้าแต่ละรายการ

โปรแกรมต้องสามารถ:

1. สร้างข้อมูลสินค้าด้วย `Box<T>`
2. แสดงชื่อสินค้า
3. แสดงราคาสินค้า
4. คำนวณราคารวมของสินค้า
5. ทดลองใช้ Dereference Operator เพื่อเข้าถึงข้อมูล

## Requirements

### 1. Product Data

กำหนดข้อมูลสินค้าอย่างน้อย 3 รายการ โดยแต่ละรายการประกอบด้วย:

- ชื่อสินค้า
- ราคา

### 2. Box Usage

- ใช้ `Box<T>` กับข้อมูลสินค้าตามความเหมาะสม
- ต้องสร้าง Box ผ่าน `Box::new()`
- ทดลองเข้าถึงข้อมูลภายใน Box

### 3. Display

แสดงข้อมูลสินค้าแต่ละรายการในรูปแบบที่อ่านง่าย

### 4. Calculation

คำนวณราคารวมของสินค้าทั้งหมด

## Constraints

- ต้องใช้ `Box<T>` อย่างน้อย 3 จุดตามการออกแบบของตนเอง
- ห้ามใช้ Global Mutable Variables
- ห้ามใช้ `unsafe`
- ห้ามใช้ `unwrap()` โดยไม่มีเหตุผล
- ต้องตั้งชื่อตัวแปรให้สื่อความหมาย

## Expected Output

ตัวอย่างรูปแบบผลลัพธ์:

```text
=== Product Information ===

Product: Keyboard
Price: 1200

Product: Mouse
Price: 500

Product: Monitor
Price: 4500

---------------------------
Total Price: 6200
```

หมายเหตุ: ชื่อและราคาสามารถกำหนดเองได้

## Hints

- ศึกษา `Box::new()`
- ทบทวนการเข้าถึง Struct Fields
- ทดลองใช้ `*` เพื่อ Dereference
- พิจารณาว่าข้อมูลส่วนใดควรอยู่บน Heap
- ตรวจสอบว่าการใช้ Box ในแต่ละตำแหน่งมีความจำเป็นหรือไม่
