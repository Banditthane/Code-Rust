# Lesson 01: Smart Pointer Basics

## วัตถุประสงค์

เรียนรู้แนวคิดของ Smart Pointer และทำความเข้าใจการจัดเก็บข้อมูลระหว่าง Stack และ Heap รวมถึงการใช้ `Box<T>` เพื่อจัดเก็บข้อมูลบน Heap

## 1. Stack และ Heap

Rust ใช้หน่วยความจำหลักสองรูปแบบที่ควรรู้จัก

### Stack

Stack ใช้จัดเก็บข้อมูลที่มีขนาดแน่นอนและจัดการตามลำดับการเรียกใช้งานของฟังก์ชัน

ตัวอย่างข้อมูลที่มักอยู่บน Stack:

- Integer เช่น `i32`, `u64`
- Boolean เช่น `bool`
- ตัวแปรที่มีขนาดแน่นอน
- References

### Heap

Heap ใช้จัดเก็บข้อมูลที่ต้องการพื้นที่หน่วยความจำแบบยืดหยุ่น หรือข้อมูลที่มีขนาดไม่ทราบแน่นอนในเวลาคอมไพล์

ตัวอย่าง:

- ข้อมูลภายใน `String`
- ข้อมูลภายใน `Vec<T>`
- ข้อมูลที่จัดเก็บผ่าน `Box<T>`

ข้อควรจำ: `String` และ `Vec<T>` มีตัวจัดการข้อมูลอยู่ในตัวแปร แต่ข้อมูลส่วนใหญ่ที่บรรจุอยู่จะถูกจัดเก็บบน Heap

## 2. Smart Pointer คืออะไร

Smart Pointer คือชนิดข้อมูลที่ทำหน้าที่คล้าย Pointer แต่มีความสามารถเพิ่มเติมในการจัดการข้อมูล เช่น

- ควบคุม Ownership
- จัดการหน่วยความจำ
- แชร์ Ownership
- ควบคุมการเข้าถึงข้อมูล
- กำหนดพฤติกรรมเมื่อข้อมูลถูกทำลาย

Smart Pointer ที่ควรรู้จัก:

| Smart Pointer | หน้าที่หลัก                                  |
| ------------- | -------------------------------------------- |
| `Box<T>`      | จัดเก็บข้อมูลบน Heap                         |
| `Rc<T>`       | แชร์ Ownership ภายใน Thread เดียว            |
| `Arc<T>`      | แชร์ Ownership ระหว่าง Threads               |
| `RefCell<T>`  | ตรวจสอบ Borrowing ขณะ Runtime                |
| `Mutex<T>`    | ควบคุมการเข้าถึงข้อมูลร่วมกันระหว่าง Threads |

## 3. Box<T>

`Box<T>` เป็น Smart Pointer ที่ใช้จัดเก็บข้อมูลบน Heap

ตัวแปรที่ถือ `Box<T>` จะเป็นเจ้าของข้อมูลนั้น และเมื่อ Box ถูกทำลาย ข้อมูลที่อยู่ภายในก็จะถูกจัดการตาม Ownership

รูปแบบการประกาศ:

```rust
let value = Box::new(10);
```

การเข้าถึงค่าภายใน Box สามารถทำได้ผ่าน Dereference

```rust
let value = Box::new(10);
println!("{}", *value);
```

ผลลัพธ์:

```text
10
```

## 4. Box กับ Recursive Data Types

Recursive Data Type คือชนิดข้อมูลที่มีการอ้างถึงตัวเองภายในโครงสร้าง

ตัวอย่างแนวคิด:

- Node มีข้อมูลหนึ่งค่า
- Node สามารถมี Node ตัวถัดไป
- Node เชื่อมต่อกันเป็น Linked List

หากเก็บ Recursive Type โดยตรง อาจทำให้ Compiler ไม่สามารถกำหนดขนาดของข้อมูลได้

การใช้ `Box<T>` ช่วยให้โครงสร้างสามารถมีข้อมูลที่เชื่อมต่อกับตัวเองได้ เพราะ Box มีขนาดที่ทราบแน่นอนในเวลาคอมไพล์

ตัวอย่างโครงสร้าง:

```rust
enum List {
    Cons(i32, Box<List>),
    Nil,
}
```

ตัวอย่างนี้เป็นเพียงการแสดงรูปแบบข้อมูล ยังไม่ใช่โปรแกรม Linked List ที่สมบูรณ์

## 5. ข้อดีของ Box<T>

- ใช้จัดเก็บข้อมูลบน Heap
- เหมาะกับข้อมูลขนาดใหญ่ที่ไม่ต้องการย้ายค่าทั้งหมด
- ใช้กับ Recursive Data Types
- มี Ownership ชัดเจน
- ไม่ต้องจัดการหน่วยความจำด้วยตนเอง

## 6. ข้อควรระวัง

- Box ไม่ได้ทำให้ข้อมูลสามารถแชร์ Ownership ได้หลายเจ้าของโดยอัตโนมัติ
- การใช้ Box ไม่ได้หมายความว่าโปรแกรมจะเร็วขึ้นเสมอ
- ควรใช้เมื่อมีเหตุผลด้านโครงสร้างข้อมูลหรือการจัดการหน่วยความจำ
- อย่าสับสนระหว่าง `Box<T>` กับ References

## 7. สรุป

- Stack เหมาะกับข้อมูลที่มีขนาดแน่นอน
- Heap เหมาะกับข้อมูลที่ต้องการพื้นที่แบบยืดหยุ่น
- Smart Pointer เพิ่มความสามารถในการจัดการข้อมูล
- `Box<T>` ใช้จัดเก็บข้อมูลบน Heap
- `Box<T>` เป็นเครื่องมือสำคัญสำหรับ Recursive Data Types
