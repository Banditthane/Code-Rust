# Exercise 04: Function Challenge

## วัตถุประสงค์

ฝึกประยุกต์ใช้ Function, Parameters และ Return Values เพื่อสร้างโปรแกรมจัดการข้อมูลคะแนนนักเรียน

## โจทย์

สร้างโปรแกรมจัดการคะแนนนักเรียน โดยแยกการทำงานแต่ละส่วนออกเป็น Function

## ข้อมูลเริ่มต้น

กำหนดคะแนนของนักเรียน 3 วิชา:

| วิชา        | คะแนน |
| ----------- | ----: |
| Mathematics |    80 |
| Science     |    70 |
| English     |    90 |

## เงื่อนไข

### ส่วนที่ 1: แสดงข้อมูลคะแนน

สร้าง Function ชื่อ `show_scores`

- รับชื่อวิชาและคะแนน
- ชื่อวิชาใช้ชนิดข้อมูล `&str`
- คะแนนใช้ชนิดข้อมูล `u32`
- แสดงชื่อวิชาและคะแนน

### ส่วนที่ 2: คำนวณคะแนนรวม

สร้าง Function ชื่อ `calculate_total`

- รับคะแนน 3 วิชา
- ใช้ชนิดข้อมูล `u32`
- ส่งผลรวมคะแนนกลับเป็น `u32`

### ส่วนที่ 3: คำนวณคะแนนเฉลี่ย

สร้าง Function ชื่อ `calculate_average`

- รับคะแนนรวม
- รับจำนวนวิชา
- คำนวณคะแนนเฉลี่ย
- ส่งผลลัพธ์กลับเป็น `f64`
- ตรวจสอบไม่ให้จำนวนวิชาเป็นศูนย์

### ส่วนที่ 4: ตรวจสอบผลสอบ

สร้าง Function ชื่อ `is_passed`

- รับคะแนนชนิด `u32`
- ตรวจสอบว่าคะแนนตั้งแต่ 50 ขึ้นไปหรือไม่
- ส่งค่ากลับเป็น `bool`
- หากคะแนนตั้งแต่ 50 ขึ้นไป ให้ส่ง `true`
- หากคะแนนต่ำกว่า 50 ให้ส่ง `false`

### ส่วนที่ 5: เรียกใช้งาน Function

ภายใน `main()`:

1. เรียก `show_scores` เพื่อแสดงคะแนนแต่ละวิชา
2. เรียก `calculate_total` เพื่อคำนวณคะแนนรวม
3. เรียก `calculate_average` เพื่อคำนวณคะแนนเฉลี่ย
4. เรียก `is_passed` เพื่อตรวจสอบผลสอบ
5. แสดงผลลัพธ์ทั้งหมดออกทางหน้าจอ

## ตัวอย่างผลลัพธ์

```text
Mathematics: 80
Science: 70
English: 90

Total Score: 240
Average Score: 80

Mathematics Passed: true
Science Passed: true
English Passed: true
```

## โจทย์เพิ่มเติม

- ทดลองเปลี่ยนคะแนนแต่ละวิชา
- ทดลองให้คะแนนวิชาใดวิชาหนึ่งต่ำกว่า 50
- ทดลองเพิ่มวิชาใหม่
- สร้าง Function ชื่อ `get_grade` เพื่อรับคะแนนและส่งเกรดกลับ
- ทดลองนำ Return Value ของ Function หนึ่งไปใช้เป็น Argument ของอีก Function หนึ่ง
