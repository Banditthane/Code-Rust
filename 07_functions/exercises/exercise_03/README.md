# Exercise 03: Return Value

## วัตถุประสงค์

ฝึกสร้าง Function ที่คำนวณข้อมูลและส่งผลลัพธ์กลับด้วย Return Value

## โจทย์

เขียนโปรแกรมเครื่องคิดเลขอย่างง่าย โดยแยกการคำนวณแต่ละประเภทออกเป็น Function

## เงื่อนไข

สร้าง Function ทั้งหมด 4 ตัว ดังนี้

| Function   | การทำงาน        | Return Type |
| ---------- | --------------- | ----------- |
| `add`      | บวกตัวเลข 2 ค่า | `i32`       |
| `subtract` | ลบตัวเลข 2 ค่า  | `i32`       |
| `multiply` | คูณตัวเลข 2 ค่า | `i32`       |
| `divide`   | หารตัวเลข 2 ค่า | `f64`       |

### ข้อกำหนด

1. แต่ละ Function ต้องรับ Parameters จำนวน 2 ตัว
2. Function ต้องคำนวณและส่งผลลัพธ์กลับ
3. ใช้ `return` หรือ Expression ท้าย Function เพื่อส่งค่ากลับ
4. เรียกใช้งาน Function จาก `main()`
5. แสดงผลลัพธ์ของการคำนวณทั้ง 4 ประเภท
6. สำหรับ Function `divide` ต้องตรวจสอบว่าตัวหารไม่เป็นศูนย์ก่อนคำนวณ

## ตัวอย่างผลลัพธ์

กำหนดให้ตัวเลขตัวแรกเป็น `20` และตัวเลขตัวที่สองเป็น `5`

```text
Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4
```

## โจทย์เพิ่มเติม

- ทดลองเปลี่ยนตัวเลขที่ใช้คำนวณ
- ทดลองใช้ตัวเลขติดลบ
- ทดลองใช้ตัวเลขทศนิยมกับ Function `divide`
- ทดลองแสดงผลลัพธ์โดยเรียก Function ภายใน `println!()` โดยตรง
- ทดลองเก็บค่าที่ Function ส่งกลับไว้ในตัวแปร
