# Exercise 01: Panic Practice

## Objective

ฝึกทำความเข้าใจ `panic!`, Unrecoverable Errors, Invalid Index และการทำงานของ `unwrap()` กับ `expect()`

## Project

`panic_practice`

## Scenario

สร้างโปรแกรมทดลองตรวจสอบข้อผิดพลาด โดยแบ่งการทดลองเป็นส่วน ๆ เพื่อสังเกตว่าเหตุการณ์ใดทำให้โปรแกรมหยุดทำงาน

## Tasks

### Part 1: Manual Panic

1. แสดงข้อความ `Program Started`
2. เรียกใช้ `panic!` พร้อมข้อความแจ้งข้อผิดพลาด
3. สังเกตผลลัพธ์ใน Terminal
4. ตรวจสอบว่าคำสั่งหลัง `panic!` ทำ
