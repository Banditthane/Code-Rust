# Exercise 03: Grade Calculator

## วัตถุประสงค์

ฝึกใช้คำสั่ง `if`, `else if` และ `else` เพื่อตรวจสอบหลายเงื่อนไข

## โจทย์

เขียนโปรแกรมคำนวณเกรดจากคะแนนสอบ โดยใช้เกณฑ์คะแนนที่กำหนด

## เกณฑ์คะแนน

| คะแนน  | เกรด |
| ------ | ---- |
| 80–100 | A    |
| 70–79  | B    |
| 60–69  | C    |
| 50–59  | D    |
| 0–49   | F    |

หากคะแนนน้อยกว่า 0 หรือมากกว่า 100 ให้แสดงข้อความ `Invalid score`

## เงื่อนไข

1. สร้างตัวแปร `score`
2. กำหนดคะแนนเริ่มต้นเป็น `75`
3. ใช้คำสั่ง `if`, `else if` และ `else`
4. ตรวจสอบคะแนนตามเกณฑ์ที่กำหนด
5. แสดงเกรดที่ตรงกับคะแนน
6. ตรวจสอบคะแนนที่อยู่นอกช่วง 0–100 ด้วย

## ตัวอย่างผลลัพธ์

เมื่อ `score = 85`

```text
Grade A
```

เมื่อ `score = 75`

```text
Grade B
```

เมื่อ `score = 45`

```text
Grade F
```

เมื่อ `score = 120`

```text
Invalid score
```

## สิ่งที่ต้องทดลอง

- ทดลองคะแนน `95`
- ทดลองคะแนน `80`
- ทดลองคะแนน `70`
- ทดลองคะแนน `60`
- ทดลองคะแนน `50`
- ทดลองคะแนน `0`
- ทดลองคะแนน `-5`
- ทดลองคะแนน `120`

- [ ] ตรวจสอบคะแนนตามช่วงได้ถูกต้อง
