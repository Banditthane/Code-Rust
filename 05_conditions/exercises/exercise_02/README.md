# Exercise 02: Pass or Fail

## วัตถุประสงค์

ฝึกใช้คำสั่ง `if else` เพื่อเลือกการทำงานระหว่าง 2 ทางเลือก

## โจทย์

เขียนโปรแกรมตรวจสอบผลสอบ โดยกำหนดคะแนนและเกณฑ์คะแนนขั้นต่ำ หากคะแนนตั้งแต่ 50 คะแนนขึ้นไปถือว่าสอบผ่าน หากต่ำกว่า 50 คะแนนถือว่าสอบไม่ผ่าน

## เงื่อนไข

1. สร้างตัวแปร `score` เพื่อเก็บคะแนน
2. กำหนดคะแนนเริ่มต้นเป็น `75`
3. ใช้คำสั่ง `if else`
4. ตรวจสอบว่า `score >= 50` หรือไม่
5. หากเป็นจริง ให้แสดงข้อความ `Pass`
6. หากเป็นเท็จ ให้แสดงข้อความ `Fail`

## ตัวอย่างผลลัพธ์

เมื่อ `score = 75`

```text
Pass
```

เมื่อ `score = 40`

```text
Fail
```

## สิ่งที่ต้องทดลอง

- ทดลองคะแนน `100`
- ทดลองคะแนน `50`
- ทดลองคะแนน `49`
- ทดลองคะแนน `0`
- สังเกตความแตกต่างของผลลัพธ์

## เกณฑ์การตรวจสอบ

- [ ] สร้างตัวแปร `score` ได้
- [ ] ใช้คำสั่ง `if else` ได้
- [ ] ใช้ตัวดำเนินการ `>=` ได้
- [ ] โปรแกรมแสดงผลสอบผ่านและไม่ผ่านได้ถูกต้อง
