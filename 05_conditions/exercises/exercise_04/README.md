# Exercise 04: Number Classifier

## วัตถุประสงค์

ฝึกใช้คำสั่ง `match` เพื่อจับคู่ค่ากับ Pattern ที่กำหนด

## โจทย์

เขียนโปรแกรมจำแนกตัวเลข โดยใช้คำสั่ง `match` ตรวจสอบค่าของตัวแปร `number`

## เงื่อนไข

1. สร้างตัวแปร `number`
2. กำหนดค่าเริ่มต้นเป็น `3`
3. ใช้คำสั่ง `match` ตรวจสอบค่าของตัวแปร
4. หากค่าเป็น `1` ให้แสดง `One`
5. หากค่าเป็น `2` ให้แสดง `Two`
6. หากค่าเป็น `3` ให้แสดง `Three`
7. หากค่าเป็น `4` ให้แสดง `Four`
8. หากค่าเป็น `5` ให้แสดง `Five`
9. หากเป็นค่าอื่น ให้แสดง `Unknown number`

## ตัวอย่างผลลัพธ์

เมื่อ `number = 3`

```text
Three
```

เมื่อ `number = 5`

```text
Five
```

เมื่อ `number = 10`

```text
Unknown number
```

## โจทย์เพิ่มเติม

ทดลองใช้เครื่องหมาย `|` เพื่อรวมหลาย Pattern เข้าด้วยกัน

ตัวอย่างแนวคิด:

- เลข 1 และ 2 ให้แสดงข้อความเดียวกัน
- เลข 3 และ 4 ให้แสดงข้อความเดียวกัน
- เลขอื่น ๆ ให้ใช้ `_` เป็นกรณีสำรอง

## สิ่งที่ต้องทดลอง

- ทดลองค่า `1` ถึง `5`
- ทดลองค่า `0`
- ทดลองค่า `10`
- ทดลองรวม Pattern ด้วย `|`

## เกณฑ์การตรวจสอบ

- [ ] ใช้คำสั่ง `match` ได้
- [ ] กำหนด Pattern ได้ถูกต้อง
- [ ] ใช้ `_` สำหรับกรณีอื่นได้
- [ ] เข้าใจการใช้ `|` เพื่อรวม Pattern
- [ ] โปรแกรมแสดงผลตามค่าที่กำหนดได้ถูกต้อง
