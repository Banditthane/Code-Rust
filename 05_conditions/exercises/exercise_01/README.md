# Exercise 01: Simple Condition

## วัตถุประสงค์

ฝึกใช้คำสั่ง `if` เพื่อตรวจสอบเงื่อนไขเบื้องต้น

## โจทย์

เขียนโปรแกรมตรวจสอบอายุของบุคคล โดยกำหนดตัวแปร `age` และตรวจสอบว่าอายุ 18 ปีขึ้นไปหรือไม่

## เงื่อนไข

1. สร้างตัวแปร `age`
2. กำหนดค่าเริ่มต้นเป็น `20`
3. ใช้คำสั่ง `if` ตรวจสอบว่า `age >= 18`
4. หากเงื่อนไขเป็นจริง ให้แสดงข้อความ `You are an adult.`
5. ยังไม่ต้องใช้ `else`

## ตัวอย่างผลลัพธ์

เมื่อ `age = 20`

```text
You are an adult.
```

เมื่อ `age = 15`

```text
ไม่มีข้อความแสดงผล
```

## สิ่งที่ต้องทดลอง

- เปลี่ยน `age` เป็น `15`
- เปลี่ยน `age` เป็น `18`
- เปลี่ยน `age` เป็น `25`
- สังเกตว่าเงื่อนไขทำงานอย่างไร

## เกณฑ์การตรวจสอบ

- [ ] สร้างตัวแปร `age` ได้
- [ ] ใช้คำสั่ง `if` ได้ถูกต้อง
- [ ] ใช้ตัวดำเนินการ `>=` ได้
- [ ] แสดงผลตามเงื่อนไขได้
