# 02: คำสั่ง if else

## ภาพรวม

คำสั่ง `if else` ใช้เมื่อต้องการให้โปรแกรมเลือกทำงานระหว่าง 2 ทางเลือก

- หากเงื่อนไขเป็น `true` ให้ทำงานในบล็อก `if`
- หากเงื่อนไขเป็น `false` ให้ทำงานในบล็อก `else`

## รูปแบบคำสั่ง

```rust
if condition {
    // ทำงานเมื่อเงื่อนไขเป็นจริง
} else {
    // ทำงานเมื่อเงื่อนไขเป็นเท็จ
}
```

## ตัวอย่าง

```rust
fn main() {
    let score = 45;

    if score >= 50 {
        println!("Pass");
    } else {
        println!("Fail");
    }
}
```

ผลลัพธ์:

```text
Fail
```

## อธิบายการทำงาน

1. กำหนดคะแนนในตัวแปร `score` เป็น `45`
2. ตรวจสอบว่า `score >= 50` หรือไม่
3. เงื่อนไขเป็น `false`
4. โปรแกรมจึงทำงานในบล็อก `else`
5. แสดงข้อความ `Fail`

## เปรียบเทียบ if กับ if else

| คำสั่ง    | การทำงาน                     |
| --------- | ---------------------------- |
| `if`      | ทำงานเมื่อเงื่อนไขเป็นจริง   |
| `if else` | เลือกทำงานระหว่าง 2 ทางเลือก |

## แบบฝึกหัด

1. สร้างตัวแปร `age` และกำหนดค่าเป็น `20`
2. ใช้ `if else` ตรวจสอบว่าอายุ 18 ปีขึ้นไปหรือไม่
3. หากอายุ 18 ปีขึ้นไป ให้แสดง `Adult`
4. หากอายุน้อยกว่า 18 ปี ให้แสดง `Minor`
5. ทดลองเปลี่ยนค่าอายุเป็น `15` แล้วตรวจสอบผลลัพธ์

## คำถามทบทวน

1. `else` ทำงานเมื่อใด?
2. `if else` แตกต่างจาก `if` อย่างไร?
3. ในคำสั่ง `if else` จะมีบล็อกใดทำงานเมื่อเงื่อนไขเป็น `false`?
