# 03: คำสั่ง else if

## ภาพรวม

คำสั่ง `else if` ใช้ตรวจสอบหลายเงื่อนไขตามลำดับ เหมาะสำหรับกรณีที่โปรแกรมมีทางเลือกมากกว่า 2 ทาง

โปรแกรมจะตรวจสอบเงื่อนไขจากบนลงล่าง และทำงานเฉพาะบล็อกแรกที่มีเงื่อนไขเป็น `true`

## รูปแบบคำสั่ง

```rust
if condition_1 {
    // ทำงานเมื่อเงื่อนไขที่ 1 เป็นจริง
} else if condition_2 {
    // ทำงานเมื่อเงื่อนไขที่ 2 เป็นจริง
} else if condition_3 {
    // ทำงานเมื่อเงื่อนไขที่ 3 เป็นจริง
} else {
    // ทำงานเมื่อทุกเงื่อนไขเป็นเท็จ
}
```

## ตัวอย่าง: การคำนวณเกรด

```rust
fn main() {
    let score = 75;

    if score >= 80 {
        println!("Grade A");
    } else if score >= 70 {
        println!("Grade B");
    } else if score >= 60 {
        println!("Grade C");
    } else if score >= 50 {
        println!("Grade D");
    } else {
        println!("Grade F");
    }
}
```

ผลลัพธ์:

```text
Grade B
```

## อธิบายการทำงาน

1. ตรวจสอบว่า `score >= 80` หรือไม่
2. หากไม่จริง ตรวจสอบ `score >= 70`
3. เมื่อเงื่อนไขที่สองเป็นจริง โปรแกรมจะแสดง `Grade B`
4. โปรแกรมจะไม่ตรวจสอบเงื่อนไขที่เหลือต่อ

## ตารางเกณฑ์คะแนน

| คะแนน  | เกรด |
| ------ | ---- |
| 80–100 | A    |
| 70–79  | B    |
| 60–69  | C    |
| 50–59  | D    |
| 0–49   | F    |

## สิ่งที่ควรระวัง

- ลำดับของเงื่อนไขมีความสำคัญ
- ควรตรวจสอบเงื่อนไขจากช่วงคะแนนสูงลงมาต่ำ
- เมื่อพบเงื่อนไขที่เป็นจริงแล้ว โปรแกรมจะไม่ตรวจสอบ `else if` ถัดไป
- หากต้องการตรวจสอบช่วงข้อมูลที่ถูกต้อง ควรเพิ่มเงื่อนไขสำหรับค่าที่อยู่นอกช่วงที่กำหนด

## แบบฝึกหัด

1. สร้างตัวแปร `score` และกำหนดคะแนนตั้งแต่ 0 ถึง 100
2. ใช้ `if`, `else if` และ `else` เพื่อกำหนดเกรด
3. ใช้เกณฑ์คะแนนตามตารางด้านบน
4. ทดลองคะแนนหลายค่า เช่น `95`, `75`, `65`, `55` และ `35`
5. เพิ่มการตรวจสอบคะแนนที่น้อยกว่า 0 หรือมากกว่า 100 โดยแสดงข้อความ `Invalid score`

## คำถามทบทวน

1. `else if` ใช้ทำอะไร?
2. โปรแกรมตรวจสอบเงื่อนไขตามลำดับอย่างไร?
3. เมื่อเงื่อนไขแรกเป็นจริง โปรแกรมจะตรวจสอบเงื่อนไขถัดไปหรือไม่?
4. เพราะเหตุใดลำดับของเงื่อนไขจึงสำคัญ?
