# บทที่ 05: เงื่อนไข (Conditions)

## ภาพรวม

บทนี้เรียนรู้การควบคุมทิศทางการทำงานของโปรแกรมด้วยเงื่อนไข (Conditions) เพื่อให้โปรแกรมสามารถตัดสินใจและเลือกทำงานตามสถานการณ์ที่กำหนดได้

## วัตถุประสงค์

เมื่อเรียนจบบทนี้แล้ว จะสามารถ:

- ใช้ `if` เพื่อตรวจสอบเงื่อนไข
- ใช้ `if else` เพื่อกำหนดการทำงานเมื่อเงื่อนไขเป็นจริงหรือเท็จ
- ใช้ `else if` เพื่อตรวจสอบหลายเงื่อนไข
- ใช้ `match` เพื่อจับคู่รูปแบบของค่า
- นำเงื่อนไขมาใช้ร่วมกับตัวแปรและตัวดำเนินการได้

## แนวคิดสำคัญ

### 1. เงื่อนไข (Condition)

เงื่อนไขคือ expression ที่ให้ผลลัพธ์เป็น `bool` ซึ่งมีได้ 2 ค่า:

- `true` หมายถึงเงื่อนไขเป็นจริง
- `false` หมายถึงเงื่อนไขเป็นเท็จ

### 2. การตัดสินใจของโปรแกรม

โปรแกรมใช้เงื่อนไขเพื่อตัดสินใจว่าจะทำคำสั่งใด เช่น:

- ตรวจสอบอายุว่าเป็นผู้ใหญ่หรือไม่
- ตรวจสอบคะแนนว่าสอบผ่านหรือไม่
- ตรวจสอบระดับคะแนนเพื่อกำหนดเกรด

### 3. การใช้เครื่องหมายเปรียบเทียบ

สามารถนำตัวดำเนินการเปรียบเทียบมาใช้สร้างเงื่อนไขได้ เช่น:

- `==` เท่ากับ
- `!=` ไม่เท่ากับ
- `>` มากกว่า
- `<` น้อยกว่า
- `>=` มากกว่าหรือเท่ากับ
- `<=` น้อยกว่าหรือเท่ากับ

- [ ] เข้าใจการทำงานของ `if`

- [ ] ใช้ `else if` ตรวจสอบหลายเงื่อนไขได้
- [ ] ใช้ `match` และ `_` ได้
