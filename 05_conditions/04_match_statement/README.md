# 04: คำสั่ง match

## ภาพรวม

คำสั่ง `match` ใช้ตรวจสอบและจับคู่ค่ากับรูปแบบ (Pattern) ที่กำหนดไว้ เหมาะสำหรับกรณีที่ต้องการแยกการทำงานตามค่าที่เป็นไปได้หลายแบบ

## รูปแบบคำสั่ง

```rust
match value {
    pattern_1 => {
        // คำสั่งเมื่อค่าตรงกับ pattern_1
    }
    pattern_2 => {
        // คำสั่งเมื่อค่าตรงกับ pattern_2
    }
    _ => {
        // คำสั่งสำหรับกรณีอื่น ๆ
    }
}
```

## ตัวอย่าง

```rust
fn main() {
    let day = 3;

    match day {
        1 => println!("Monday"),
        2 => println!("Tuesday"),
        3 => println!("Wednesday"),
        4 => println!("Thursday"),
        5 => println!("Friday"),
        6 => println!("Saturday"),
        7 => println!("Sunday"),
        _ => println!("Invalid day"),
    }
}
```

ผลลัพธ์:

```text
Wednesday
```

## อธิบายการทำงาน

1. กำหนดค่า `day` เป็น `3`
2. โปรแกรมนำค่าไปตรวจสอบกับแต่ละ Pattern ใน `match`
3. เมื่อพบ Pattern ที่ตรงกับค่า คือ `3`
4. โปรแกรมจะแสดงข้อความ `Wednesday`

## เครื่องหมายที่ควรรู้

### 1. เครื่องหมาย `=>`

ใช้แยก Pattern ออกจากคำสั่งที่จะทำงานเมื่อ Pattern นั้นตรงกับค่า

```rust
1 => println!("One"),
```

### 2. เครื่องหมาย `_`

เรียกว่า Wildcard ใช้แทนกรณีอื่น ๆ ที่ไม่ได้ระบุไว้โดยตรง

```rust
_ => println!("Other"),
```

### 3. เครื่องหมาย `|`

ใช้ระบุหลาย Pattern ที่ต้องการให้ทำงานแบบเดียวกัน

```rust
match number {
    1 | 2 | 3 => println!("Number is between 1 and 3"),
    _ => println!("Other number"),
}
```

## สิ่งที่ควรรู้

- `match` ต้องครอบคลุมค่าที่เป็นไปได้ทั้งหมด
- สามารถใช้ `_` เป็นกรณีสำรองได้
- สามารถใช้ `|` เพื่อรวมหลาย Pattern ได้
- แต่ละแขนง (Arm) สามารถมีคำสั่งมากกว่าหนึ่งคำสั่งได้เมื่อใช้ `{}`

## แบบฝึกหัด

1. สร้างตัวแปร `number` และกำหนดค่าเป็นตัวเลขตั้งแต่ 1 ถึง 5
2. ใช้ `match` ตรวจสอบค่าของตัวแปร
3. หากเป็น 1 ให้แสดง `One`
4. หากเป็น 2 ให้แสดง `Two`
5. หากเป็น 3 ให้แสดง `Three`
6. หากเป็น 4 ให้แสดง `Four`
7. หากเป็น 5 ให้แสดง `Five`
8. ใช้ `_` เพื่อแสดง `Unknown number` สำหรับค่าอื่น ๆ
