# 01: คำสั่ง if

## ภาพรวม

คำสั่ง `if` ใช้ตรวจสอบเงื่อนไข หากเงื่อนไขเป็น `true` โปรแกรมจะทำงานภายในบล็อกคำสั่ง แต่หากเป็น `false` โปรแกรมจะข้ามบล็อกคำสั่งนั้น

## รูปแบบคำสั่ง

```rust
if condition {
    // คำสั่งที่ต้องการให้ทำงานเมื่อเงื่อนไขเป็นจริง
}
```

## ตัวอย่าง

```rust
fn main() {
    let age = 20;

    if age >= 18 {
        println!("You are an adult.");
    }
}
```

ผลลัพธ์:

```text
You are an adult.
```

## อธิบายการทำงาน

1. สร้างตัวแปร `age` และกำหนดค่าเป็น `20`
2. ตรวจสอบเงื่อนไข `age >= 18`
3. เงื่อนไขเป็น `true` เพราะ 20 มากกว่าหรือเท่ากับ 18
4. โปรแกรมจึงทำงานคำสั่ง `println!()`

หากเปลี่ยน `age` เป็น `15` เงื่อนไขจะเป็น `false` และโปรแกรมจะไม่แสดงข้อความ

## สิ่งที่ควรรู้

- เงื่อนไขของ `if` ต้องให้ผลลัพธ์เป็น `bool`
- สามารถใช้ตัวดำเนินการเปรียบเทียบได้
- ไม่จำเป็นต้องใส่วงเล็บ `()` รอบเงื่อนไข
- ต้องใช้ `{}` เพื่อกำหนดขอบเขตของคำสั่ง
- หากเงื่อนไขเป็น `false` และไม่มี `else` โปรแกรมจะข้ามบล็อกนั้น

## แบบฝึกหัด

1. สร้างตัวแปร `temperature` และกำหนดค่าเป็น `35`
2. ใช้ `if` ตรวจสอบว่าอุณหภูมิมากกว่า `30` หรือไม่
3. หากเป็นจริง ให้แสดงข้อความ `It is hot.`
4. ทดลองเปลี่ยนค่าเป็น `25` แล้วสังเกตผลลัพธ์
