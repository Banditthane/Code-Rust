# Exercise 04: Data Structure Challenge

## Objective

ประยุกต์ใช้ Vector, HashMap และ Nested Data ร่วมกันเพื่อสร้างโปรแกรมจัดเก็บคะแนนนักเรียน

## Project Structure

```text
exercise_04/
├── README.md
└── data_structure_challenge/
    ├── Cargo.toml
    └── src/
        └── main.rs
```

## Scenario

ต้องการสร้างโปรแกรมเก็บคะแนนสอบของนักเรียนหลายคน โดยนักเรียนแต่ละคนมีคะแนนหลายวิชา

กำหนดให้:

- ชื่อนักเรียนเป็น Key
- คะแนนของนักเรียนเป็น Vector
- ใช้ HashMap จัดเก็บข้อมูลนักเรียนทั้งหมด

ตัวอย่างข้อมูล:

| Student | Scores     |
| ------- | ---------- |
| Alice   | 80, 90, 85 |
| Bob     | 70, 75, 80 |
| Charlie | 90, 85, 95 |

## Requirements

1. Import `HashMap`
2. สร้าง HashMap ชื่อ `students`
3. เพิ่มข้อมูลนักเรียนอย่างน้อย 3 คน
4. แต่ละคนต้องมีคะแนน 3 วิชา
5. ใช้ `.get()` เพื่อค้นหาคะแนนของนักเรียน
6. ใช้ Loop เพื่อแสดงชื่อนักเรียนและคะแนนทุกวิชา
7. คำนวณผลรวมคะแนนของนักเรียนแต่ละคน
8. คำนวณคะแนนเฉลี่ยของนักเรียนแต่ละคน
9. ใช้ `.insert()` เพื่อเพิ่มนักเรียนอีก 1 คน

## Constraints

- ต้องใช้ `HashMap`
- ต้องใช้ `Vec<i32>` เป็นข้อมูลคะแนน
- ต้องใช้ Nested Data
- ต้องใช้ `.get()` สำหรับค้นหาข้อมูล
- ต้องใช้ Loop แสดงข้อมูล
- ต้องใช้ Loop สำหรับคำนวณผลรวม
- ต้องคำนวณค่าเฉลี่ยโดยไม่ใช้ค่าคงที่ที่กำหนดไว้ล่วงหน้า
- ต้องแสดงค่าเฉลี่ยเป็นทศนิยม 2 ตำแหน่ง
- ต้องไม่สมมติว่าลำดับการแสดงผลของ HashMap คงที่

## Expected Output

ตัวอย่างผลลัพธ์ที่ต้องการ:

```text
Student: Alice
Scores: [80, 90, 85]
Total: 255
Average: 85.00

Student: Bob
Scores: [70, 75, 80]
Total: 225
Average: 75.00

Student: Charlie
Scores: [90, 85, 95]
Total: 270
Average: 90.00
```

หมายเหตุ:

- ลำดับนักเรียนอาจแตกต่างกัน
- คะแนนและผลรวมต้องถูกต้อง
- ค่าเฉลี่ยต้องแสดงทศนิยม 2 ตำแหน่ง
