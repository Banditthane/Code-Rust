# Exercise 01: String Basics

## วัตถุประสงค์

ฝึกสร้างและใช้งาน String รวมถึงทำความเข้าใจความแตกต่างระหว่าง `String` และ `&str`

## โจทย์

สร้างโปรแกรมแนะนำตัวเองโดยใช้ชนิดข้อมูลข้อความทั้ง `String` และ `&str`

## เงื่อนไข

1. สร้างตัวแปร `name` ชนิด `String` โดยเก็บชื่อของตนเอง
2. สร้างตัวแปร `country` ชนิด `&str` โดยเก็บชื่อประเทศ
3. สร้างตัวแปร `language` ชนิด `String` โดยเก็บชื่อภาษาโปรแกรมที่กำลังเรียน
4. แสดงข้อมูลทั้งหมดออกทางหน้าจอ
5. สร้าง Function ชื่อ `show_info` โดยรับ Parameter ชนิด `&str`
6. ทดลองส่งตัวแปร `String` เข้า Function ผ่านการอ้างอิง

## ตัวอย่างผลลัพธ์

```text
Name: Alex
Country: Thailand
Language: Rust
Welcome, Alex!
```

หมายเหตุ: สามารถเปลี่ยนข้อมูลเป็นของตนเองได้

## โจทย์เพิ่มเติม

- สร้าง String ว่างด้วย `String::new()`
- ทดลองเพิ่มข้อความด้วย `push_str()`
- ทดลองเพิ่มตัวอักษรด้วย `push()`
- ทดลองส่ง String Literal เข้า Function
