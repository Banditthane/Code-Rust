# Exercise 03: String Methods

## วัตถุประสงค์

ฝึกใช้ String Methods เพื่อค้นหา ตรวจสอบ และแปลงข้อความ

## โจทย์

สร้างโปรแกรมจัดการข้อความที่กำหนด โดยใช้ String Methods ต่าง ๆ

## ข้อมูลเริ่มต้น

กำหนดข้อความ:

```rust
let message = String::from("  Hello Rust Programming  ");
```

## เงื่อนไข

### ส่วนที่ 1: ตรวจสอบความยาว

1. ใช้ `len()` ตรวจสอบความยาวของข้อความ
2. แสดงผลลัพธ์ออกทางหน้าจอ

### ส่วนที่ 2: ตรวจสอบข้อความ

1. ใช้ `contains()` ตรวจสอบว่ามีคำว่า `Rust` หรือไม่
2. ตรวจสอบว่ามีคำว่า `Java` หรือไม่
3. แสดงผลลัพธ์เป็น `true` หรือ `false`

### ส่วนที่ 3: จัดการข้อความ

1. ใช้ `trim()` เพื่อตัดช่องว่างด้านหน้าและด้านหลัง
2. ใช้ `replace()` เปลี่ยนคำว่า `Rust` เป็น `Java`
3. แสดงข้อความหลังการเปลี่ยนแปลง

### ส่วนที่ 4: แปลงตัวอักษร

1. ใช้ `to_uppercase()` แปลงข้อความเป็นตัวพิมพ์ใหญ่
2. ใช้ `to_lowercase()` แปลงข้อความเป็นตัวพิมพ์เล็ก
3. แสดงผลลัพธ์ทั้งสองแบบ

### ส่วนที่ 5: ตรวจสอบ String ว่าง

1. สร้าง String ว่างด้วย `String::new()`
2. ใช้ `is_empty()` ตรวจสอบข้อความ
3. แสดงผลลัพธ์

## ตัวอย่างผลลัพธ์

```text
Length: 26
Contains Rust: true
Contains Java: false
Trimmed: Hello Rust Programming
Replaced: Hello Java Programming
Uppercase: HELLO RUST PROGRAMMING
Lowercase: hello rust programming
Is Empty: true
```

หมายเหตุ: ตัวเลขความยาวขึ้นอยู่กับข้อความที่กำหนด และ `len()` นับจำนวนไบต์

## โจทย์เพิ่มเติม

- ทดลองใช้ข้อความภาษาไทย
- เปรียบเทียบ `len()` กับ `chars().count()`
- ทดลองเปลี่ยนคำค้นหาใน `contains()`
- ทดลองแทนที่ข้อความมากกว่าหนึ่งตำแหน่ง
