# Exercise 02: String Operations

## วัตถุประสงค์

ฝึกสร้าง String เพิ่มข้อความ และต่อข้อความด้วย Methods ที่ภาษา Rust เตรียมไว้ให้

## โจทย์

สร้างโปรแกรมสำหรับประกอบข้อความแนะนำตัว โดยใช้ `String::new()`, `push_str()` และ `push()`

## เงื่อนไข

### ส่วนที่ 1: สร้างข้อความ

1. สร้าง String ว่างชื่อ `message`
2. ใช้ `push_str()` เพิ่มข้อความ `My name is `
3. ใช้ `push_str()` เพิ่มชื่อตนเอง
4. ใช้ `push()` เพิ่มเครื่องหมาย `!`

### ส่วนที่ 2: ต่อข้อความ

1. สร้าง String ชื่อ `country`
2. กำหนดชื่อประเทศของตนเอง
3. ใช้เครื่องหมาย `+` หรือ `format!()` เพื่อประกอบข้อความ
4. แสดงข้อความทั้งหมด

### ส่วนที่ 3: ทดลองเปลี่ยนแปลงข้อความ

1. สร้าง String ชื่อ `language`
2. เพิ่มข้อความด้วย `push_str()`
3. เพิ่มเครื่องหมายด้วย `push()`
4. แสดงข้อความก่อนและหลังเพิ่มข้อมูล

## ตัวอย่างผลลัพธ์

```text
My name is Alex!
Country: Thailand
Learning: Rust!
```

หมายเหตุ: ใช้ข้อมูลของตนเองได้

## โจทย์เพิ่มเติม

- ทดลองใช้ `String::from()` แทน `String::new()`
- ทดลองต่อ String หลายตัว
- ทดลองใช้ `+` และ `format!()` แล้วเปรียบเทียบ
- สังเกตว่า String ตัวใดถูกย้าย Ownership เมื่อใช้ `+`
