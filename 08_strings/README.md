# บทที่ 08: Strings (การจัดการข้อความ)

## ภาพรวม

บทนี้เรียนรู้การจัดเก็บและจัดการข้อความในภาษา Rust โดยทำความเข้าใจชนิดข้อมูลข้อความที่สำคัญ ได้แก่ `String` และ `&str` รวมถึงการสร้างข้อความ การต่อข้อความ การตรวจสอบข้อความ และการจัดรูปแบบข้อความ

## วัตถุประสงค์

เมื่อเรียนจบบทนี้แล้ว จะสามารถ:

- เข้าใจความแตกต่างระหว่าง `String` และ `&str`
- สร้าง String ด้วย `String::from()` และ `String::new()` ได้
- เพิ่มข้อความด้วย `push()` และ `push_str()` ได้
- อ่านความยาวของข้อความด้วย `len()` ได้
- ตรวจสอบข้อความด้วย `contains()` และ `is_empty()` ได้
- แทนที่ข้อความด้วย `replace()` ได้
- ตัดช่องว่างด้วย `trim()` ได้
- แปลงตัวอักษรเป็นตัวพิมพ์ใหญ่และตัวพิมพ์เล็กได้
- จัดรูปแบบข้อความด้วย `format!()` ได้

## แนวคิดสำคัญ

### 1. String

`String` เป็นชนิดข้อมูลข้อความที่สามารถเพิ่ม เปลี่ยนแปลง และจัดการเนื้อหาได้ โดยมีการจัดเก็บข้อมูลบน Heap

### 2. String Slice (&str)

`&str` เป็น String Slice ใช้สำหรับอ้างอิงข้อความ โดยไม่ได้เป็นเจ้าของข้อมูลข้อความนั้น

### 3. UTF-8

ข้อความใน Rust ใช้การเข้ารหัส UTF-8 ดังนั้นความยาวของ String ที่ได้จาก `len()` จะนับเป็นจำนวนไบต์ ไม่ใช่จำนวนตัวอักษรที่ผู้ใช้มองเห็นเสมอไป

### 4. String Methods

Rust มี Methods สำหรับจัดการข้อความ เช่น:

- `len()`
- `is_empty()`
- `push()`
- `push_str()`
- `contains()`
- `replace()`
- `trim()`
- `to_uppercase()`
- `to_lowercase()`

### 5. String Formatting

ใช้ `format!()` เพื่อสร้างข้อความจากข้อมูลหลายส่วน โดยไม่จำเป็นต้องพิมพ์ข้อความออกหน้าจอทันที

## ตัวอย่างเบื้องต้น

```rust
fn main() {
    let name = String::from("Rust");

    println!("Hello, {}!", name);
}
```

ผลลัพธ์:

```text
Hello, Rust!
```
