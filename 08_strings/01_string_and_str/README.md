# 01: String และ &str

## ภาพรวม

ภาษา Rust มีชนิดข้อมูลที่ใช้จัดการข้อความที่สำคัญ 2 รูปแบบ ได้แก่ `String` และ `&str`

ทั้งสองชนิดใช้เก็บหรืออ้างอิงข้อความได้ แต่มีความแตกต่างกันในเรื่องการเป็นเจ้าของข้อมูลและการจัดการข้อความ

## 1. String คืออะไร?

`String` เป็นชนิดข้อมูลข้อความที่สามารถเปลี่ยนแปลงเนื้อหาได้ และเป็นเจ้าของข้อมูลข้อความของตัวเอง

ตัวอย่าง:

```rust
fn main() {
    let name = String::from("Rust");

    println!("{}", name);
}
```

ผลลัพธ์:

```text
Rust
```

## 2. &str คืออะไร?

`&str` หรือ String Slice เป็นการอ้างอิงข้อความ โดยไม่ได้เป็นเจ้าของข้อมูลข้อความนั้น

ตัวอย่าง:

```rust
fn main() {
    let name: &str = "Rust";

    println!("{}", name);
}
```

ผลลัพธ์:

```text
Rust
```

## 3. ความแตกต่างระหว่าง String และ &str

| หัวข้อ                | String                              | &str                                 |
| --------------------- | ----------------------------------- | ------------------------------------ |
| ลักษณะ                | เป็นเจ้าของข้อมูลข้อความ            | อ้างอิงข้อความ                       |
| การเปลี่ยนแปลงเนื้อหา | สามารถเพิ่มหรือต่อข้อความได้        | ไม่สามารถแก้ไขข้อความผ่าน `&str` ได้ |
| การสร้าง              | `String::from()`                    | String Literal เช่น `"Rust"`         |
| การใช้งาน             | ข้อความที่ต้องจัดการหรือเปลี่ยนแปลง | ข้อความที่ต้องการอ่านหรืออ้างอิง     |

## 4. ตัวอย่างการใช้งานร่วมกัน

```rust
fn greet(name: &str) {
    println!("Hello, {}!", name);
}

fn main() {
    let name = String::from("Alex");

    greet(&name);
}
```

ผลลัพธ์:

```text
Hello, Alex!
```

อธิบาย:

- `name` เป็น `String`
- `&name` เป็นการส่งการอ้างอิงไปยังข้อความ
- Function `greet` รับข้อมูลเป็น `&str`
- สามารถส่ง `&String` ให้ Function ที่รับ `&str` ได้ผ่านการแปลงอ้างอิงอัตโนมัติของ Rust

## 5. String Literal

ข้อความที่เขียนอยู่ในเครื่องหมาย Double Quotes เช่น `"Hello"` เรียกว่า String Literal

ตัวอย่าง:

```rust
fn main() {
    let message = "Hello, Rust!";

    println!("{}", message);
}
```

ตัวแปรนี้มีชนิดข้อมูลเป็น `&str` จากการอนุมานชนิดข้อมูลของ Rust

## สิ่งที่ควรรู้

- `String` เป็นเจ้าของข้อมูลข้อความ
- `&str` เป็นการอ้างอิงข้อความ
- String Literal มีชนิดข้อมูลเป็น `&str`
- สามารถส่ง `String` แบบอ้างอิงให้ Function ที่รับ `&str` ได้
- ไม่สามารถแก้ไขข้อความผ่าน `&str` โดยตรงได้

## แบบฝึกหัด

1. สร้างตัวแปร `name` ชนิด `String` โดยใช้ `String::from()`
2. สร้างตัวแปร `country` ชนิด `&str`
3. แสดงค่าของตัวแปรทั้งสอง
4. สร้าง Function ชื่อ `show_message` โดยรับ Parameter ชนิด `&str`
5. ทดลองส่ง String และ String Literal เข้า Function
6. สังเกตความแตกต่างของ `String` และ `&str`
