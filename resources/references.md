# Rust Learning References

แหล่งข้อมูลหลักและเอกสารอ้างอิงสำหรับการเรียนรู้ภาษา Rust ใน Repository นี้

## 1. Main Learning Resource

### W3Schools — Rust Tutorial

https://www.w3schools.com/rust/

ใช้เป็นแหล่งเรียนรู้พื้นฐานตามลำดับหัวข้อ เช่น:

- Rust Introduction
- Syntax and Output
- Variables and Data Types
- Operators
- Conditions and Loops
- Functions
- Strings
- Ownership and Borrowing
- Arrays, Vectors and Tuples
- Structs and Enums

## 2. Official Documentation

### The Rust Programming Language — The Rust Book

https://doc.rust-lang.org/book/

ใช้ศึกษาแนวคิดและรายละเอียดของภาษา Rust อย่างเป็นระบบ

### Rust Standard Library

https://doc.rust-lang.org/std/

ใช้ค้นหา API และรายละเอียดการใช้งาน Standard Library

### The Cargo Book

https://doc.rust-lang.org/cargo/

ใช้ศึกษา Cargo สำหรับจัดการโปรเจกต์ Dependencies และการ Build

### Rust Reference

https://doc.rust-lang.org/reference/

ใช้ตรวจสอบรายละเอียดทางภาษาและ Syntax ในระดับลึก

## 3. Additional Learning References

### Rust by Example

https://doc.rust-lang.org/rust-by-example/

เรียนรู้ผ่านตัวอย่างโค้ดที่สามารถทดลองได้

### Rustlings

https://github.com/rust-lang/rustlings

แบบฝึกหัด Rust ที่ช่วยฝึกแก้ไขโค้ดและทำความเข้าใจภาษา

## 4. Reference Usage Rules

- ใช้ W3Schools เป็นเส้นทางเรียนพื้นฐาน
- ใช้ Rust Book เพื่อศึกษาแนวคิดเพิ่มเติม
- ใช้ Official Documentation เมื่อต้องการตรวจสอบรายละเอียด
- ระบุแหล่งที่มาของตัวอย่างหรือเนื้อหาที่นำมาใช้
- ไม่คัดลอกเนื้อหาจากแหล่งอื่นมาเผยแพร่โดยไม่ตรวจสอบเงื่อนไขการใช้งาน

## 5. Notes

รายการอ้างอิงนี้สามารถเพิ่มเติมได้เมื่อมีการเรียนรู้หัวข้อใหม่หรือพบแหล่งข้อมูลที่มีประโยชน์
