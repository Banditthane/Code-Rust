## 5. Development Commands

คำสั่งที่ใช้บ่อยระหว่างพัฒนา:

```powershell
# ตรวจสอบ Rust Version
rustc --version

# ตรวจสอบ Cargo Version
cargo --version

# สร้างโปรเจกต์ใหม่
cargo new my_project

# รันโปรแกรม
cargo run

# ตรวจสอบโค้ด
cargo check

# รันทดสอบ
cargo test

# จัดรูปแบบโค้ด
cargo fmt

# ตรวจสอบคุณภาพโค้ด
cargo clippy
```

## 6. Useful Reminders

- ใช้ Cargo จัดการ Rust Projects
- ใช้ Rust Playground ทดลองโค้ดสั้น ๆ
- ใช้ docs.rs ค้นหา Documentation ของ Libraries
- ใช้ rust-analyzer ช่วยตรวจสอบโค้ดใน Editor
- อ่าน Documentation ก่อนนำ Library มาใช้
