# Exercise 04: Collection Challenge

## Objective

สร้างระบบจัดการข้อมูลนักเรียนโดยใช้ `Vec`, `String` และ `HashMap` ร่วมกับ Iterator เพื่อฝึกประยุกต์ใช้ Collections ในสถานการณ์จริง

## Project

Project Name: `collection_challenge`

## Scenario

โรงเรียนต้องการโปรแกรมจัดเก็บรายชื่อนักเรียนและคะแนนสอบ โดยมีข้อมูลนักเรียนดังนี้:

| Student | Score |
| ------- | ----: |
| Alice   |    85 |
| Bob     |    72 |
| Charlie |    90 |
| David   |    65 |
| Eve     |    78 |

## Requirements

### Part 1: Store Data

1. สร้าง `Vec<String>` ชื่อ `students` สำหรับเก็บรายชื่อนักเรียน
2. สร้าง `HashMap<String, u32>` ชื่อ `scores` สำหรับเก็บคะแนน
3. เพิ่มรายชื่อนักเรียนทั้ง 5 คน
4. เพิ่มคะแนนของนักเรียนแต่ละคน

### Part 2: Display Data

1. วนซ้ำรายชื่อนักเรียนด้วย Iterator
2. ค้นหาคะแนนของนักเรียนแต่ละคนจาก HashMap
3. แสดงชื่อและคะแนน
4. จัดการกรณีที่ไม่มีคะแนนใน HashMap

### Part 3: Process Data

1. คำนวณคะแนนรวมด้วย Iterator และ `sum()`
2. คำนวณคะแนนเฉลี่ย
3. ใช้ `filter()` เพื่อค้นหานักเรียนที่ได้คะแนนตั้งแต่ 80 ขึ้นไป
4. ใช้ `map()` เพื่อสร้างรายการชื่อของนักเรียนที่ผ่านเงื่อนไข
5. ใช้ `collect()` เพื่อรวบรวมผลลัพธ์เป็น Vector

### Part 4: Statistics

แสดงข้อมูลต่อไปนี้:

- จำนวนนักเรียนทั้งหมด
- คะแนนรวม
- คะแนนเฉลี่ย
- จำนวนนักเรียนที่ได้คะแนนตั้งแต่ 80 ขึ้นไป
- รายชื่อผู้ที่ได้คะแนนตั้งแต่ 80 ขึ้นไป

## Constraints

- ต้องใช้ `Vec<String>` สำหรับรายชื่อนักเรียน
- ต้องใช้ `HashMap<String, u32>` สำหรับคะแนน
- ต้องใช้ `iter()` หรือการวนซ้ำผ่าน Reference
- ต้องใช้ `get()` เพื่อค้นหาคะแนน
- ต้องใช้ `filter()` เพื่อกรองนักเรียน
- ต้องใช้ `map()` เพื่อแปลงข้อมูล
- ต้องใช้ `collect()` เพื่อสร้าง Vector ใหม่
- ต้องใช้ `sum()` เพื่อคำนวณคะแนนรวม
- ต้องใช้ `len()` เพื่อนับจำนวนนักเรียน
- ต้องจัดการกรณีค้นหาคะแนนไม่พบ
- ห้ามใช้ `unwrap()` กับข้อมูลที่อาจไม่มี
- ต้องตรวจสอบก่อนหาร เพื่อป้องกันการหารด้วยศูนย์

## Expected Output

```text
Student Scores:
Alice: 85
Bob: 72
Charlie: 90
David: 65
Eve: 78

Total Students: 5
Total Score: 390
Average Score: 78.00
Students Scoring 80 or Above: 2

Qualified Students:
Alice
Charlie
```

## Hints

- ใช้ `students.iter()` เพื่ออ่านรายชื่อโดยไม่ย้าย Ownership
- ใช้ `scores.get(name)` เพื่อค้นหาคะแนน
- ใช้ `filter()` เพื่อเลือกนักเรียนที่ได้คะแนนตามเกณฑ์
- ใช้ `map()` เพื่อแปลง Reference ของชื่อเป็น String ที่ต้องการเก็บใน Vector
- ใช้ `collect::<Vec<String>>()` หรือระบุชนิดของตัวแปรปลายทาง
- ใช้ `sum::<u32>()` เพื่อรวมคะแนน
- ใช้ `f64` เมื่อต้องการคำนวณและแสดงคะแนนเฉลี่ยเป็นทศนิยมสองตำแหน่ง
