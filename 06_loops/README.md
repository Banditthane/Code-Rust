# บทที่ 06: Loops (การวนซ้ำ)

## ภาพรวม

บทนี้เรียนรู้การใช้คำสั่งวนซ้ำ (Loops) เพื่อให้โปรแกรมสามารถทำงานเดิมหลายครั้งได้ โดยไม่จำเป็นต้องเขียนคำสั่งเดิมซ้ำ ๆ

## วัตถุประสงค์

เมื่อเรียนจบบทนี้แล้ว จะสามารถ:

- เข้าใจแนวคิดของการวนซ้ำ
- ใช้ `loop` เพื่อวนซ้ำอย่างต่อเนื่อง
- ใช้ `break` เพื่อออกจากการวนซ้ำ
- ใช้ `continue` เพื่อข้ามรอบปัจจุบัน
- ใช้ `while` เพื่อวนซ้ำตามเงื่อนไข
- ใช้ `for` เพื่อวนซ้ำตามช่วงข้อมูล
- เลือกใช้ Loop ให้เหมาะสมกับสถานการณ์

## แนวคิดสำคัญ

### 1. Loop

Loop คือการสั่งให้โปรแกรมทำงานซ้ำตามรูปแบบหรือเงื่อนไขที่กำหนด

### 2. Break

`break` ใช้หยุดการวนซ้ำและออกจาก Loop

### 3. Continue

`continue` ใช้ข้ามคำสั่งที่เหลือในรอบปัจจุบัน แล้วเริ่มรอบถัดไป

### 4. While

`while` ใช้ตรวจสอบเงื่อนไขก่อนเริ่มแต่ละรอบ หากเงื่อนไขเป็น `true` จะทำงานต่อไป

### 5. For

`for` ใช้วนซ้ำกับข้อมูลหรือช่วงข้อมูลที่กำหนด เช่น ช่วงตัวเลขและสมาชิกใน Array

## เปรียบเทียบ Loop

| คำสั่ง  | ลักษณะการทำงาน                 |
| ------- | ------------------------------ |
| `loop`  | วนซ้ำต่อเนื่องจนกว่าจะสั่งหยุด |
| `while` | วนซ้ำตราบใดที่เงื่อนไขเป็นจริง |
| `for`   | วนซ้ำตามสมาชิกหรือช่วงข้อมูล   |
