# 01: คำสั่ง loop

## ภาพรวม

คำสั่ง `loop` ใช้สั่งให้โปรแกรมวนซ้ำอย่างต่อเนื่อง โดยจะไม่หยุดเองจนกว่าจะมีคำสั่งให้ออกจาก Loop เช่น `break`

## รูปแบบคำสั่ง

```rust
loop {
    // คำสั่งที่ต้องการให้ทำงานซ้ำ
}
```

## ตัวอย่าง

```rust
fn main() {
    let mut count = 1;

    loop {
        println!("Count: {}", count);

        count += 1;

        if count > 5 {
            break;
        }
    }
}
```

ผลลัพธ์:

```text
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
```

## อธิบายการทำงาน

1. สร้างตัวแปร `count` และกำหนดค่าเริ่มต้นเป็น `1`
2. เริ่มทำงานภายใน `loop`
3. แสดงค่าปัจจุบันของ `count`
4. เพิ่มค่า `count` ขึ้น 1
5. ตรวจสอบว่า `count > 5` หรือไม่
6. หากเป็นจริง จะใช้ `break` เพื่อออกจาก Loop
7. หากเป็นเท็จ จะเริ่มรอบใหม่

## คำสั่ง break

`break` ใช้หยุดการทำงานของ Loop ทันที

ตัวอย่าง:

```rust
fn main() {
    let mut number = 1;

    loop {
        if number == 4 {
            break;
        }

        println!("{}", number);
        number += 1;
    }
}
```

ผลลัพธ์:

```text
1
2
3
```

## คำสั่ง continue

`continue` ใช้ข้ามคำสั่งที่เหลือในรอบปัจจุบัน แล้วเริ่มรอบถัดไป

ตัวอย่าง:

```rust
fn main() {
    let mut number = 0;

    loop {
        number += 1;

        if number == 3 {
            continue;
        }

        if number > 5 {
            break;
        }

        println!("{}", number);
    }
}
```

ผลลัพธ์:

```text
1
2
4
5
```

## สิ่งที่ควรรู้

- `loop` จะวนซ้ำต่อเนื่อง
- ต้องมีวิธีหยุด Loop หากไม่ต้องการให้ทำงานตลอดไป
- `break` ใช้ออกจาก Loop
- `continue` ใช้ข้ามรอบปัจจุบัน
- สามารถใช้ตัวแปรร่วมกับ Loop ได้

## แบบฝึกหัด

1. สร้างตัวแปร `count` โดยกำหนดค่าเริ่มต้นเป็น `1`
2. ใช้ `loop` เพื่อแสดงตัวเลขตั้งแต่ 1 ถึง 10
3. เพิ่มค่าตัวแปรทีละ 1 ในแต่ละรอบ
4. ใช้ `break` เพื่อหยุดเมื่อแสดงเลข 10 แล้ว
5. ทดลองใช้ `continue` เพื่อข้ามเลข 5
