# 03: คำสั่ง for loop

## ภาพรวม

คำสั่ง `for` ใช้สำหรับวนซ้ำตามสมาชิกของข้อมูลหรือช่วงข้อมูลที่กำหนด เช่น ช่วงตัวเลข (Range) และสมาชิกภายใน Array

เหมาะสำหรับกรณีที่ทราบว่าต้องการวนซ้ำกับข้อมูลชุดใด

## รูปแบบคำสั่ง

```rust
for variable in collection {
    // คำสั่งที่ต้องการให้ทำงานซ้ำ
}
```

## ตัวอย่าง: วนซ้ำตามช่วงตัวเลข

```rust
fn main() {
    for number in 1..6 {
        println!("{}", number);
    }
}
```

ผลลัพธ์:

```text
1
2
3
4
5
```

## อธิบาย Range

Rust ใช้ Range เพื่อกำหนดช่วงของตัวเลข

| รูปแบบ  | ความหมาย                |
| ------- | ----------------------- |
| `1..5`  | เริ่มที่ 1 และไม่รวม 5  |
| `1..=5` | เริ่มที่ 1 และรวม 5     |
| `0..10` | เริ่มที่ 0 และไม่รวม 10 |

ตัวอย่าง:

```rust
fn main() {
    for number in 1..=5 {
        println!("{}", number);
    }
}
```

ผลลัพธ์:

```text
1
2
3
4
5
```

## ตัวอย่าง: วนซ้ำกับ Array

```rust
fn main() {
    let numbers = [10, 20, 30, 40, 50];

    for number in numbers {
        println!("{}", number);
    }
}
```

ผลลัพธ์:

```text
10
20
30
40
50
```

## ตัวอย่าง: ใช้ rev() นับถอยหลัง

```rust
fn main() {
    for number in (1..=5).rev() {
        println!("{}", number);
    }
}
```

ผลลัพธ์:

```text
5
4
3
2
1
```

## สิ่งที่ควรรู้

- `for` ใช้วนซ้ำตามข้อมูลหรือช่วงข้อมูล
- `1..5` ไม่รวมเลข 5
- `1..=5` รวมเลข 5
- สามารถใช้ `for` กับ Array ได้
- สามารถใช้ `.rev()` เพื่อวนซ้ำจากท้ายไปต้นใน Range ได้

## แบบฝึกหัด

1. สร้างโปรแกรมโดยใช้ `for`
2. แสดงตัวเลขตั้งแต่ 1 ถึง 20
3. ทดลองเปลี่ยนจาก `1..20` เป็น `1..=20`
4. สร้าง Array ที่มีตัวเลข 5 ค่า
5. ใช้ `for` วนซ้ำเพื่อแสดงสมาชิกทุกตัวใน Array
6. ทดลองใช้ `.rev()` เพื่อแสดงตัวเลขจากมากไปน้อย
