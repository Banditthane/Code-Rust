# Exercise 01: Basic Calculator

## Objective

ฝึกใช้งาน Arithmetic Operators เพื่อสร้างโปรแกรมคำนวณพื้นฐาน

## Requirements

สร้างตัวแปรจำนวนเต็ม 2 ตัว:

- `a` กำหนดค่าเป็น 20
- `b` กำหนดค่าเป็น 6

จากนั้นคำนวณและแสดงผลลัพธ์ดังนี้:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Remainder

## Expected Output

```text
a = 20
b = 6

Addition: 26
Subtraction: 14
Multiplication: 120
Division: 3
Remainder: 2
```

## Requirements Checklist

- [ ] ประกาศตัวแปร `a` และ `b`
- [ ] ใช้ `+`
- [ ] ใช้ `-`
- [ ] ใช้ `*`
- [ ] ใช้ `/`
- [ ] ใช้ `%`
- [ ] แสดงผลลัพธ์ด้วย `println!()`

## Run

```powershell
cargo run
```
