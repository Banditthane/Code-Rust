# Exercise 02: Comparison Challenge

## Objective

ฝึกใช้ Comparison Operators เพื่อเปรียบเทียบข้อมูล

## Requirements

สร้างตัวแปร:

- `age` มีค่าเป็น 20
- `score` มีค่าเป็น 75
- `passing_score` มีค่าเป็น 50

เขียนโปรแกรมตรวจสอบเงื่อนไข:

1. อายุเท่ากับ 20 หรือไม่
2. อายุไม่เท่ากับ 18 หรือไม่
3. คะแนนมากกว่า 50 หรือไม่
4. คะแนนน้อยกว่า 100 หรือไม่
5. คะแนนมากกว่าหรือเท่ากับคะแนนผ่านหรือไม่
6. คะแนนน้อยกว่าหรือเท่ากับ 75 หรือไม่

## Expected Output

```text
Age is 20: true
Age is not 18: true
Score is greater than 50: true
Score is less than 100: true
Passed: true
Score is less than or equal to 75: true
```

## Requirements Checklist

- [ ] ประกาศตัวแปรทั้ง 3 ตัว
- [ ] ใช้ `==`
- [ ] ใช้ `!=`
- [ ] ใช้ `>`
- [ ] ใช้ `<`
- [ ] ใช้ `>=`
- [ ] ใช้ `<=`
- [ ] แสดงผลลัพธ์ Boolean
